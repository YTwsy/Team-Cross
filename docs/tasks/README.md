# 任务记录与历史归档

这里试行按需记录任务、完成后归档的文档组织方式。当前项目知识仍由 [Agent Wiki](../agent-wiki/README.md) 维护。

## 什么时候需要任务文件

默认不创建任务文档。能在当前对话与代码差异中讲清楚的小改动，在提交或 PR 中简要说明改动与实际检查即可。是否需要记录取决于中断接续、交接和调查复杂度；验证力度仍按 [验证门槛](../agent-wiki/sources/validation/test-gates.md) 与变更风险决定。

| 情况 | 记录方式 |
| --- | --- |
| 状态栏折叠、局部布局或文案调整 | 通常无需任务文件，保留必要检查与交付说明 |
| 跨会话推进，需要保留当前判断和下一步 | 一份 `docs/tasks/<task-id>.md` 即可 |
| 多方案调查或多环境验收，单文件已不便阅读 | 使用 `docs/tasks/<task-id>/README.md`，按需拆出 `validation.md` 等材料 |

这些形式按实际需要选择，不是每个任务都要填写的模板。若已有任务系统维护负责人、完成状态和下一步，任务文件只保留需要补充的调查或证据，不独立维护另一套状态。

下面是目录关系示例；示例中的任务文件不需要预先创建：

```text
docs/
├── agent-wiki/                     当前事实、决策、验证要求与导航
└── tasks/
    ├── README.md                   本规则
    ├── <task-id>.md                按需创建的活跃任务记录
    ├── <complex-task>/             内容较多时才拆为目录
    │   ├── README.md               目标、当前判断、下一步
    │   └── validation.md           按需保留的本次验证结果
    └── finished_archived/          已结束记录，默认检索排除
```

## 当前知识与执行记录

- `sources/decisions/` 维护当前采用的方案、原因及重新评估条件。
- `sources/validation/` 维护可复用的验证方法、通过标准和结论边界。
- `wiki/concepts/` 维护短小的上下文与来源入口。
- 任务记录保存本次目标、临时判断、执行观察和未完成事项。实际验证写明被测提交、环境、检查、结果、证据位置与未覆盖项；若包含未提交改动，也应明确说明。

开发过程中，确定下来的长期知识及时更新到本分支的对应来源与短页面，并与代码一起审查、合入。恢复既有行为的普通 fix 不必新增决策或修改概念页。不要等到合入时才第一次整理全部知识，也不要把整份执行报告搬进 `sources/validation/`。

## 收尾与归档

1. 确认仍然有效的设计与验证要求已进入当前文档；尚需继续处理的问题进入活跃任务或当前限制说明。
2. 保留本次实际结果、版本、环境和未覆盖项。归档表示这轮任务或记录已收尾，不表示所有场景均已通过。
3. 将任务文件或目录移到 `docs/tasks/finished_archived/`，修复指向它及其内部的相对链接，并随本次文档改动提交到 Git。

归档保留当时的判断与证据，不随新实现改写成当前结论。已有单份验收报告可以保留原文件名直接归档，不必补建目录或 README。大型日志、临时产物和凭据不进入文档；重要外部证据要有明确的保存位置，单独留下本机临时路径不等于已长期保存。

## 检索边界

仓库根目录的 `.ignore` 将 `docs/tasks/finished_archived/` 排除出普通 `rg` 与 `rg --files`。归档文件仍由 Git 跟踪，不加入 `.gitignore`。默认不扫描、批量读取归档，也不把历史报告清单追加到 Wiki 索引或验证短页面。

用户要求追溯历史，或当前资料不足以解释具体问题时，可以定向检索并读取相关记录，无需把全部归档装入上下文。从仓库根目录运行：

```sh
# 当前文档与活跃任务，保留默认排除规则。
rg -n -- '关键词' docs

# 已有明确的历史问题时，只检索归档区。
rg --no-ignore -n -- '关键词' docs/tasks/finished_archived
```

当前文档可以保留必要的历史证据链接；沿链接读取归档前，应明确要追溯的问题，核对记录版本与当前实现，不把历史通过结果直接用于新版本。

`.ignore` 是默认检索规则，不是访问权限。直接读取、其他搜索工具或覆盖过滤的参数仍可访问归档；全文或向量索引需要单独排除这个目录。
