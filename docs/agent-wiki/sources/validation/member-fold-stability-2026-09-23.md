# 2026-09-23 短页面成员折叠稳定性验证

## 范围与原因

修复 `v0.2.3` 协作详情在短页面末尾反复跳动的问题。本次从 `8d3e390` 开始验证，发布准备前快进同步到 `b459027`；两者之间只有 README 修改。环境为 macOS 14.8.5 / arm64、Go 1.27.1、Node 24.18.0、pnpm 11.19.0，浏览器为 Microsoft Edge。

通过只读 API 在独立 Vite 页面加载反馈中的已关闭空间：一份折叠的材料和一条批注。原版本向下滚动后，成员卡片自动收起使页面总高度减小，浏览器将滚动位置限制到新的页面底部；详情网格因此回到展开阈值，重新展开又触发收起。停止输入后的 2.5 秒采样记录到 52 次状态翻转，`scrollY` 在 396.5 至 445 CSS px 之间往返。

[成员组件](../../../../packages/web/src/components/Members.tsx) 在进入阅读阶段时记录右栏最后一个内容块的底边，保留右栏实际内容的最低高度。成员仍可动画收起、批注仍向上移动，但页面可滚动范围不随该动画缩小。回到概览、变为窄屏顺序布局或卸载时释放预留。测量不采用被左侧长正文拉伸后的整栏高度，避免切回短材料列表时留下巨大空白；监听阶段状态也随 effect 生命周期重新初始化，覆盖 StrictMode 清理与重建。

## 检查与结果

- Web check、9 个文件共 122 项测试、production build 通过，已更新 `internal/webassets/dist` 并构建本地 CLI。
- 新增回归覆盖短页面末尾的滚动范围、持续滚动事件、回到概览、长正文切回短列表、窄屏与卸载清理，以及在阅读位置挂载时的 StrictMode 重建。既有手动展开、焦点保护和临界缓冲回归通过。
- `go test ./...`、`go vet ./...` 及验证契约中的七个 Go 包 race test 通过。后续正式构建仍由 tag 流水线重新检查。
- 实际页面 2.5 秒采样中成员仅收起一次，卡片高度从约 214.39 px 变为 73 px，`scrollY` 始终为 500，document 高度始终为 1340 px。
- 在 `1440×900`、`1024×900`、`768×900` 的深浅主题下复核六个视图与截图：双栏只折叠一次，768 px 顺序布局保持展开，各次采样滚动位移和横向溢出均为 0。
- 减少动态效果模式下，成员直接收起且滚动位置保持 440；回到概览恢复展开并清除预留高度。预览控制台没有 error。

## 边界与收尾

测试仅涉及 WebGUI 布局和现有空间的只读加载，没有发布材料、修改批注、重新开放空间或调用真实模型。此次结果不扩展为原生客户端、两台 Mac、LAN 或 Tailcat 验收。

已恢复测试页的临时视口与媒体模拟，并关闭测试页面；原有 Core 与用户浏览器页面保留。版本发布及安装检查以 `v0.2.4` 的 tag 流水线为准。
