## 浏览器结果

1. “已发布会话材料 / 协作上下文”直接位于同一个阅读面板标题栏，发布、选择和刷新操作随当前内容显示。两部分高度相同，保留已展开材料及读取状态。
2. 实际鼠标往返切换时，外层页面 `scrollY` 均为 400，材料内部从 428 切到上下文的 0，再返回 428；切换不跳动整页。
3. 材料展开后只有一个材料选择入口。收藏后显示高亮星标与“已收藏”，刷新后仍存在；取消后刷新保持“收藏”。写入失败保留原状态并显示原因由组件用例覆盖。
4. 材料专注阅读隐藏侧栏，切到未启用专注的上下文后恢复侧栏。点击材料批注的“查看原位置”自动回到材料标签并高亮对应引用。
5. 当前模式在标题旁以紧凑入口展示，展开查看固定模式与权限说明。材料的批注提示和专注按钮位于选择/收藏工具栏，上下文的同类操作位于内容类型栏；正文前没有独立提示行。
6. 最终构建在 `1440×900`、`1024×900`、`768×900` 的浅色与深色下，分别检查材料和上下文，共 12 个视图。实际 CSS 尺寸经 DOM 确认；页面和阅读区均无横向溢出，两种内容的面板标题栏高度一致。已保存并查看截图，浏览器控制台无 error。

本地证据位于忽略目录 `bin/reading-tabs-evidence/`，包括 `materials-{light,dark}-{1440,1024,768}.png`、`context-{light,dark}-{1440,1024,768}.png` 与 `viewport-checks.json`。浏览器存在缩放，尺寸以 DOM 读数为准。
