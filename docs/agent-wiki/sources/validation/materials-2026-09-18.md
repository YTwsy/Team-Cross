# 2026-09-18 只读空间与会话材料

本记录对应 `codex/collaboration-spaces` 中与本文件一起提交的实现，基于 `50e89d3` 的多成员基础。环境为 macOS 14.8.5 arm64、Go 1.27.1、Node 24.18.0、Vite 7.1.7、Vitest 3.2.4。没有更新安装渠道，也没有替换用户正在使用的 Core。

## 实现与自动检查

空间记录采用 `schema:2` 和可选 `execution`；独立空间不要求 Git 目录，不 fork、resume 或发送模型输入。范围冻结与预览只在发布者本机；空间保存明确选择的可见历史与工具内容。材料版本不可覆盖，读取分页、批注与回复固定版本，撤回停止原文读取。WebGUI、个人 MCP/CLI、共享运行时读取使用同一材料对象。

通过 `go test ./...`、`go vet ./...`，以及 `internal/collab`、`internal/mcp`、`internal/sharing`、`internal/nativecodex`、`internal/nativeclaude`、`internal/service`、`internal/cliinstall` 的 race test。最终只读邀请状态修正后，再运行协作包 test/vet/race。Web 类型检查、61 项测试和生产构建通过，更新 `internal/webassets/dist`。

[材料回归](../../../../internal/collab/materials_test.go) 覆盖：

- 无执行空间、来源目录不存在仍可发布、已完成范围固定，后来产生的内容不自动加入。
- 材料目录无正文；原生 history/file/changes/events、来源枚举、草稿与原生连接入口不向只读成员开放；公开范围外的引用拒绝。
- 发布持久去重、重启后查询、同请求改内容拒绝、固定 v1/v2、更新基准检查、保存失败回滚。
- A/B/C 三 Core；每人独立发布，同请求 ID 不串作者，C 不能修改 B 材料；移除 B 后 C 仍可读取已发布材料。
- 创建执行保留讨论、只 fork 一次、关闭旧只读凭据；成员首次读取已失效邀请仍保持只读形态，不填造执行字段。
- 撤回后原文不可读；已保存回复的重试仍返回原结果，新回复不能附已撤回材料。
- 导出不含隐藏推理、未知字段、外部图片内容；保存的工具输出保留，缺失内容有说明；大输出分页及 UTF-16 定位、跨材料/空间游标拒绝。

[Web 回归](../../../../packages/web/src/test/materials.test.tsx) 覆盖目录不自动读正文/原生上下文、发布不确定结果的稳定重试、旧附件不随新版本变化、更新保留原范围、边界缺失须重选、失效只读资格的新邀请入口。[Claude 历史回归](../../../../internal/nativeclaude/history_test.go) 补工具结果与未导出附件说明。

## 真实浏览器流程

使用 [浏览器 fixture](../../../../internal/collab/materials_browser_test.go) 提供真实 HTTP、嵌入式生产 Web 资源和三个独立 Core，成员连接经过实际 TLS。来源为合成会话，原生运行时为测试替身；不使用用户的 Session、不启动模型。

在 Codex 内置浏览器完成：

1. A 的只读空间显示 A/B/C；Bob 选自己的来源，排除前置无关轮次，预览并发布一轮材料，包含已保存工具输出。
2. Bob 的批注同时附 A.v1、B.v1；B 主动发布 v2 新增验证，旧附件保持 v1 并提示新版本。
3. Carol 从旧批注打开 B.v1，仍只看到旧范围，再回复并附 B.v2；讨论作者为具体成员。
4. 更新默认保留上次首末轮与建议起点；“引用这段文字”把固定版本原文带入编辑区，并实际保存成功。
5. Bob 从新建入口选择范围、预览、创建独立只读空间并进入邀请说明，不要求执行目录。
6. A 从只读空间启用执行，页面明确新增范围、来源、目录、模式和重新邀请；完成后材料与原文批注保留，旧 Carol 凭据不能读取原生上下文。
7. 最终构建复核失效只读空间入口、材料撤回及提示；控制台检查无应用错误。

检查 1440、1024、768 CSS 像素下的深浅主题与材料页面截图，并读取实际 `innerWidth/scrollWidth` 确认无水平溢出。检查范围表单、预览、单列/双列布局、材料正文、固定版本下拉、原文引用与焦点进入批注。浏览器临时视口覆盖结束后恢复。

## 证据边界与收尾

这是同一台 Mac 的三个 Core 与浏览器验证，不是三台 Mac 的 LAN/Tailcat 验收；本轮未发起真实模型、原生 TUI/Desktop 操作或真实 Tailcat/DERP 流量。原生来源导出的真实客户端版本差异仍需专门测试 Session 验收，不能从合成历史推出所有版本兼容。

成员身份目前只在一次共享周期内延续；结束共享再加入会产生新身份，不能更新旧身份的发布材料。更新后的材料仍是可见内容的固定快照，不是可原生恢复的完整 Session；附件文件不复制，复杂内容或超长项明确提示缺失/截断。当前支持轮次变化数量，尚无逐字版本 diff 或材料全文搜索。旧扁平记录保留但不加载，无自动迁移。

浏览器 fixture 使用独立临时目录和显式 `finish` 标记退出，关闭本次服务器、Core 与测试运行时；关闭本次浏览器页。保留用户的原生会话和其他运行进程。文档相对链接、代码路径、索引、旧能力引用与 `git diff --check` 在提交前检查。
