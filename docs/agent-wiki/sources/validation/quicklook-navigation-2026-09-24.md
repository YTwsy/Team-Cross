# 2026-09-24 状态栏协作速览

基线为 `a70c002` 加本次工作区改动，环境为 macOS 14.8.5、Go 1.27.1、Node 24.18.0、Swift 6.0.3。行为约定见 [资源库与速览](../decisions/resource-library.md#macos-协作速览)。

## 行为与修复

- [速览界面](../../../../packages/web/src/components/QuickLook.tsx) 提供平级的“当前协作”和“资源速览”，默认显示当前协作。复用协作列表与状态显示，排除已结束、已离开的空间，保留只读、执行、断线和需要处理的空间；支持按发起/加入筛选、打开对应详情，以及切回视图和窗口获得焦点时刷新。
- [资源界面](../../../../packages/web/src/components/Library.tsx) 保留切换前的搜索、筛选和选择；隐藏时不响应搜索快捷键。固定状态由原生确认事件更新。“服务与设置”与资源筛选同处一行，英文长标签允许换行。
- [速览样式](../../../../packages/web/src/library.css) 移除列表独立高度与滚动、窄屏额外底部留白和强制不换行。选择栏收起时贴近视口底部，展开清单或读取入口后进入正常页面布局，自动滚动到可见位置；展开内容不再嵌套滚动或覆盖资源列表。
- [App 外壳](../../../../apps/macos/TeamCross.swift) 的菜单入口和浮窗标题改为“协作速览”，并纳入此前尚未提交的 `NSMenu.appearance = NSApp.effectiveAppearance` 调整。

## 浏览器验证

使用 [独立资源库 fixture](../../../../internal/collab/library_browser_test.go) 加载本次 production build。测试空间、HTTP、Core 和存储真实，来源会话及执行运行时为合成内容；原生 `WKScriptMessageHandler` 由浏览器内的消息记录器替代，不启动模型。

通过 agent-browser 0.38.1 驱动 Chrome，捕获 26 个视图并复核关键截图：

1. `470×650` 弹窗和 `420×440` 最小浮窗，覆盖中英文、深浅主题、当前协作与资源速览，共 16 个视图。没有横向溢出或页面内嵌套滚动；服务入口与首行筛选对齐，英文筛选自然换行。
2. 空选择、五项选择展开、读取入口及入口详情，共四个视图。空状态在标准弹窗内不产生多余纵向滚动；最小浮窗可通过页面滚动访问完整清单和入口详情。
3. 实际滚轮操作会移动页面，资源列表自身 `scrollTop` 保持为零。切换视图后搜索条件与选择仍保留。
4. 消息记录器收到对应协作详情路由、两个视图的服务菜单请求和固定请求；固定按钮按确认事件更新。真实 Core 完成五项资源选择和固定读取入口生成。
5. 完整资源库在 `1440×900`、`1024×900`、`768×900` 的深浅主题下复核，共六个视图，原有导航与布局正常；页面无横向溢出，浏览器没有页面脚本错误。
