## 浏览器结果

1. 材料与上下文正文随 document 滚动，阅读面板 `overflow-y: visible`，不再保留固定高度的内部纵向滚动区。展开 48 行工具日志后，正文内仍无纵向滚动容器。
2. 双栏阅读工具栏吸顶到距视口顶部约 12 px，正文下方仍可切换材料、上下文类型、目录和专注状态。窄窗口工具栏按实际高度换行。
3. 材料在 `scrollY = 976` 切到上下文再返回时恢复 976，同一段落距视口顶部保持 425.16 px。最终构建在稳定视口中切入与退出专注阅读，同一段落保持 429.82 px；修复了退出时目录响应宽度晚一帧造成的偏移。
4. 成员初始完整显示。滚动触发折叠后，采样得到正文高度约 `411 → 386 → 300 → 233 → 143 → 86 → 0` px，透明度逐步降到 0；动画期间 document 的 `scrollY` 持续为 480，没有因卡片收缩跳动。保留标题、人数和展开按钮，减少动态效果模式下取消动画。
5. 使用真实坐标点击展开后，从 `scrollY = 480` 继续滚动到 580，成员保持展开；回到概览自动展开。768 px 的顺序布局保持完整成员信息，不自动收起。
6. 768 px 下目录浮层为纵向列表，边界位于视口内，选中轮次后关闭；目标轮次顶部约 135.22 px，工具栏底部约 119.20 px，保留约 16 px 间距。
7. 底部选择栏收起高度约 55.33 px。展开长日志并滚到页面末尾后，最后提示段落底部约 747.65 px，选择栏顶部约 826.67 px，正文没有被覆盖。
8. 材料与上下文分别在 `1440×900`、`1024×900`、`768×900` 的浅色、深色下复核，共 12 个视图。尺寸以实际 DOM 读数确认，均无页面横向溢出；已保存并查看截图，最终测试页面控制台无 error。

截图及 DOM 记录位于本地忽略目录 `bin/reading-scroll-evidence/`，包括两种内容的 12 张 PNG、`viewport-checks.json` 与 `member-transition.json`。浏览器缩放与 Retina 比例需要分别校准，截图像素尺寸不等同于 CSS 视口尺寸。
