# 产品功能与用户流程基准

个人 Agent 和终端可以通过与 WebGUI 相同的 Core 入口选择来源、预览、创建新 fork、生成邀请、加入、管理输入和结束/恢复。命令与 MCP 参数见 [协议](protocol.md#个人-mcp-管理入口)；完整使用示例见 [README](../../../README.md)。明确来源选择与调用者的个人 Provider 独立；“当前 Session”则必须核对原生调用身份，登记后等待本轮完成再创建。创建与邀请分步持久化；邀请失败保留协作。TUI 打开新窗口，不接管当前终端；客户端启动不会自动取得输入权。

此文档记录 main 的产品方向，避免后续实现重新引入已经去掉的概念。

统一用词见 [产品核心与词汇](product-core-and-glossary.md)，面向用户的启动与操作说明见 [README](../../../README.md)。

| 功能 | 用户流程 | 结束时得到什么 |
| --- | --- | --- |
| 浏览协作 | 打开首页 → 查看最近活动 → 全部/我发起的/我加入的 | 清晰的协作名称、项目、执行主机、共享与运行状态 |
| 选择来源 | 发起协作 → 搜索历史 → 选择已完成轮所在的会话 | 来源引用，尚未发送任何指令 |
| 分享当前 Session | 个人 Agent 核对当前会话 → 预览目录、模式和传输 → 登记请求 → 结束本轮 → 下一轮查询并取回邀请 | 包含本轮完整答复的新 fork；等待可取消，来源变化或重启不自动创建 |
| 原目录协作 | 选择“使用原目录” → 查看当前现场与起点 → 创建 | 新会话 ID，原分支、暂存区、文件保持原状 |
| 独立目录协作 | 选择“创建新 worktree” → 查看提交、分支、目标目录 → 创建 | 新会话 ID 与从 HEAD 创建的干净目录 |
| 选择协作模式 | 确认工作现场 → 保留默认受限或主动选择信任 → 重新预览并创建 | 两种 Provider 均支持，模式创建后固定；恢复沿用，详情与邀请确认页可见 |
| 邀请同事 | 详情 → 显式选择局域网或实验性 Tailcat → 生成并复制邀请 → 同事本机粘贴 | A 保持执行主机，B 通过所选传输获得此协作的访问；不自动回退 |
| 直接 TUI | 等待输入交接 → 打开 Codex → TUI | 本机终端连接 A 的共享 fork |
| 直接 Desktop | 等待输入交接 → 打开 Codex → Desktop | 专用 Desktop 实例连接 A 的共享 fork |
| 辅助 TUI | 用自己的客户端辅助 → 选择个人 Codex / Claude Code → 一次性 MCP 配置 → 打开 TUI → 工具选择目标 | 独立本地会话读取或参与共享协作 |
| 辅助 Desktop | 选择个人 Codex → 打开普通 Desktop | 独立本地会话使用相同工具 |
| 邀请者定位 Codex fork | 创建成功 → 详情“在个人 Codex 中打开” | 主动点击后按 fork ID 打开个人 Desktop；远端活动和交接不自动切换页面，释放后可在个人 Codex 中继续 |
| 邀请者定位 Claude fork | 创建后完成首次业务输入 → Claude 持久化原生 fork | fork 自动进入 A 的个人 CLI/TUI `/resume` 历史；释放后可继续，零输入 fork 不要求先落盘 |
| 并行辅助 | 保持直接客户端 → 再打开辅助入口 | 工具可并行读取；写入统一协调 |
| 输入交接 | A 交出 → B 输入；B 交还或 A 接回 | 明确的当前输入者与连接变更 |
| 选择模型 | 在 Codex 中选择模型与推理强度 → 继续输入 | A 使用原生运行时确认的配置；WebGUI 展示实际设置 |
| 运行中参与 | 在 Codex/MCP 补充、中断、回应审批 | 指令送入原生运行时，实际结果单独读取 |
| 查看上下文 | 详情 → 最近对话/代码改动/文件/技术信息 | 轻量历史、代码参考和按需技术信息 |
| 回复批注 | 在原批注下展开回复 → 填写并保存 | 单层讨论，不创建新批注，不改变原文定位 |
| 人工批注 | 选择对话文字或代码行 → 核对原文 → 输入意见 → 保存；整体意见从批注面板添加 | 带原文片段和结构化位置的协作批注，不自动发送给模型 |
| 客户端切换 | 关闭当前直接客户端 → 选择另一个 | 同一个协作 fork 与执行目录 |
| 服务恢复 | 重新启动 Core → 协作列表 → 继续 | A 恢复同一已持久化 fork 后重新选择传输并邀请；B 单独重启后用已保存的加入资格和原传输重连；Claude 零输入 fork 可能需重新创建 |
| 结束共享 | 结束共享 → 完成当前执行和审批 → 关闭专用客户端 | 自动释放原生会话占用；会话与代码保留，无成果提交门槛 |
| 离开协作 | B 主动离开 → 主机撤销加入资格 | 输入归还 A；再次参与需要新邀请 |
| 主题与配置 | 设置 → 系统/浅色/深色 → 客户端与 MCP | 本机持久化偏好和接入信息 |

信任模式允许当前输入者使用邀请者的原生有效配置和权限，涵盖 MCP、插件、hooks、网络、命令及已启用的浏览器/电脑控制，可能访问仓库外资源并使用邀请者的服务身份；仍遵循原生与系统授权。完整范围及生命周期见 [协作模式决策](decisions/runtime-modes.md)。

发起、结束协作均不要求提出问题、生成摘要、收集独立 Evidence 或验证成果。是否提交代码、导出 patch、创建 PR，由用户在自己的开发工具中决定。

流程变更同时更新本页、[产品模型](../wiki/concepts/product-model-and-glossary.md) 和对应的界面或客户端上下文。已完成的客户端组合见 [2026-09-09 验收记录](validation/native-collaboration-2026-09-09.md)，不能将流程描述本身当作实测结果。

## 邀请与持续访问

邀请码的一小时期限仅限制首次加入。加入成功后，关闭客户端、休眠、断网或重启 B 的 Core 都不撤销资格；输入交接只改变当前输入者。只有主动离开、A 结束共享或 A 退出/重启 Core 才终止这次访问。已使用的邀请码不能接纳另一人；未使用而到期、或同事主动离开后，A 可以生成新邀请。

连接方式是邀请的一部分。LAN 发布私有 IPv4 候选；实验性 Tailcat 邀请携带 Tailcat 地址并依赖 DERP 引导。用户明确选择其一，系统不在创建或断线时自动探测、降级或切换。两种传输使用相同 TLS pin 和成员凭据；邀请内容都按秘密处理。

结束共享后等待执行、审批、已接收请求和直接连接清空，再关闭本次会话的 app-server。只读上下文不恢复该运行时；显式恢复继续原来的 `sessionId`、目录和最新持久化模型配置。

## 上下文阅读

详情页首屏将执行主机、使用目录、当前输入者和共享状态放在同一张执行信息卡中；共享详情以浮层按需展开，不增加页面常驻高度。右侧信息区先显示紧凑的参与协作，再显示批注；技术信息作为“协作上下文”的最后一个标签。窄屏可以让上下文和右侧信息区顺序下排，但不改变这组信息的归属。

批注从原处发起：对话可选择文字或整条消息，文件和 diff 可通过行旁按钮选择单行，或拖选同一文件、同一侧、同一 hunk 的连续行。批注面板常驻编辑框，选择原文后直接展示引用并聚焦，不弹出窗口。不同引用与整体意见分别保留草稿，保存失败和上下文刷新保留正文；浏览器整页刷新或离开页面不保证保留。每条批注可展开单层回复，所有回复归属原批注，显示作者与时间。批注面板可复制适用于直接或辅助客户端的处理提示。

“查看原位置”重新读取上下文。对话根据原生 turn/item 和文字范围定位，目标不在当前页时按 cursor 查找更早历史；一次自动查找最多 20 页，可以继续手动翻页。代码只有内容指纹、文件、行范围和片段一致时才高亮；diff 同时检查基准提交和 old/new 一侧。内容变化或位置找不到时保留批注时的片段并说明原因，不猜测新位置。浅色和深色均提供高亮。

保存批注只记录协作意见，当前输入归属不因批注改变。直接 Codex TUI/Desktop 和 Claude Code TUI 的共享运行时可主动调用当前协作的批注读取与回复工具；个人辅助客户端使用完整 Team Cross MCP。共享 fork 的执行模型不会仅因为保存批注或回复而收到新输入。需要分析或处理时由用户明确提出，发送仍走现有输入协调。批注位置与快照的协议见 [批注引用](protocol.md#批注引用)。

同一协作、标签和文件的自动或手动刷新保留已加载内容，避免加载占位改变页面高度、重建对话容器或重置阅读位置；收到新结果后在原位置更新。首次加载、切换标签或查看另一文件时使用各自的加载状态，不把前一个资源的内容当作新结果。后台刷新失败时保留最近一次成功读取的内容，同时显示错误和重试入口。
