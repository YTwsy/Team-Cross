# 创建时固定的协作模式

## 产品决策

邀请者在创建协作时选择 `restricted`（受限模式，默认）或 `trusted`（信任模式）。两种 Provider 均支持。第一版不提供模式切换；预览、创建去重、持久化、恢复和邀请声明均绑定该模式。用户显式选择信任模式，表示授权当前输入者在这次共享 fork 中使用邀请者的原生运行环境。

信任模式继承个人及当前执行目录下的原生有效配置，包括 MCP、插件、hooks、记忆、网络和命令权限、浏览器与电脑控制等可用能力。它不强制 full-access、跳过审批、绕过组织要求或 macOS 授权，也不把原来关闭或不可用的能力自动启用。模型选择继续使用来源和后续原生设置。

继承的是主机上可解析的配置以及 Core 可获得的环境；不是来源进程所有临时命令行参数、环境变量和 Desktop 进程私有服务的精确快照。恢复使用同一种模式与当时原生有效配置。新 worktree 的项目配置按新执行目录解析，不复制来源未提交文件。

## 用户可见语义

创建页显示两个模式及其作用；模式选择变化必须重新确认预览。信任模式可能在创建或恢复时启动个人 MCP 和生命周期 hooks，创建仍不发送业务 prompt。邀请确认页展示声明的模式，连接后的详情以主机实际记录为准，双方都能看到固定模式与授权范围。

工具在 A 运行，使用 A 的服务身份。读取结果进入共享会话，写入可能影响外部服务、其他目录或个人资源。因此信任模式不能宣传为“所有能力只在当前仓库内”或“协作者绝不可能看到其他个人资料”。接回输入和结束共享撤销后续入口访问，不会回滚已经发生的工具操作；正在执行的调用需要按原生能力处理中断。

## Codex 实现

受限模式继续注入 `teamcross-native` 权限、功能禁用项，并逐个禁用继承 MCP。信任模式的独立 app-server 使用 A 的 `CODEX_HOME`，不注入这些覆盖，只合并完整的当前协作批注 MCP；枚举 MCP 与启动使用同一模式，避免插件动态 transport 不一致。同名个人 MCP 保留，批注 MCP 选择未占用名称。

创建与恢复固定新 fork 身份、执行目录和当前工作区根，信任模式让原生运行时解析权限、审批及其他配置。当前输入者可以通过原生会话设置选择权限，受组织要求约束；携带权限变更的 `thread/resume` 同样属于写入。创建通过 `deferGoalContinuation` 避免源目标在 fork 时自动开始业务输入。

原生 hooks/skills 发现只解析 A 的执行目录，响应保留客户端请求 cwd 的查找键，使远端 TUI 能完成启动；它不会按 B 提供的路径读取 A 的其他目录。

专用客户端的信任模式配置不再把受限默认值发回共享运行时。网关仍只暴露指定会话，客户端账户和一般偏好保持本机路由，配置读取继续隐藏原始 MCP 配置、配置来源和认证 token。原生 hook 审阅是明确的例外：仅 `hooks.state` 配置写入送到 A，并检查信任模式、当前输入者和请求去重，不接受任意配置路径或混入其他设置；原生确认结果由 Codex 保存到 A 的配置。Team Cross 不自动信任新增或改变的 hooks。这是网关行为边界，不是对信任模式 Agent 或第三方工具可读数据的额外沙箱保证。

## Claude Code 实现

受限模式沿用独立 `claude-runtime`、来源快照和私有配置。信任模式直接使用邀请者的原生个人配置目录，在该目录中创建新的原生 fork，不传入受限 settings、空 setting-sources、strict MCP、工具白名单、manual 权限模式或 no-chrome。默认配置目录和显式 `CLAUDE_CONFIG_DIR` 的 `.claude.json` 查找区别随协作保存。

信任模式的协作目录只保存所有权标记，原生配置和历史由 Claude 自身管理。批注工具以本次协作唯一名称追加。恢复校验固定模式和精确 job；结束仅停止本次 job，不停止可能服务其他个人会话的 daemon；原生 stop 返回后，等待 daemon 确认 worker 不再 alive 且不再 present，避免提前恢复产生另一个 session。Claude Desktop 仍不支持；原生 TUI、MCP 辅助和输入协调的已有能力边界保持有效。

## 验证

回归必须覆盖默认受限、无效模式、预览与创建模式不一致、重试不改变模式、同 ID 恢复、工具配置继承、权限设置的输入归属、配置过滤和结束访问。Claude 另验证默认配置位置、原生环境变量、个人配置不被 Team Cross 改写、精确 job 停止且个人 daemon 保留。真实验证只使用专用会话和 `gpt-5.6-luna`，与浏览器截图、实际 Desktop/电脑控制验收分开记录。
