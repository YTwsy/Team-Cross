# 个人资源库与资源速览

## 目的与入口

协作材料、原文批注和执行上下文需要反复带给个人或共享 Agent。资源库统一这些内容的查找、阅读和选择，减少逐条复制 UUID 与工具说明。WebGUI 主导航保留“协作空间”“设置与连接”，新增“资源库”。设置页原有主题、客户端和 MCP 接入功能继续保留。

资源库按 Session 分组，提供最近使用、我参与的、我批注的、已收藏视图，以及标题、Session、作者、批注文字搜索和类型筛选。点击标题阅读，勾选加入选择，星标收藏，三种动作互相独立。“我批注的”依据具体成员 `authorId`，包含本人回复过的讨论及关联材料，不按可能重名的显示名称判断。列表只索引本机发起或已加入空间中可见的内容，不扫描个人原生会话。

阅读继续记录最近打开时间，但阅读、勾选、收藏、定时同步和窗口重新获得焦点都保留当前条目及分组顺序，避免操作中的内容跳到列表顶部。同步立即更新正文摘要、选择、收藏与访问状态，移除已消失的资源，新条目追加到所属分组末尾，新分组追加到列表末尾。点击资源库顶部的“刷新”或重新加载页面时，才采用服务端最新的最近使用排序；排序不写入持久化数据。

宽屏在列表旁阅读材料和批注，窄屏使用完整阅读区域与返回列表入口。阅读器复用固定版本、Markdown、按条展开、原文定位和回复能力；读取时核对当前访问范围。正文只在当前页面内存中暂存，失去访问后清除预览，不作为离线全文收藏。

## 选择与个人读取入口

材料、批注、协作上下文以及历史/文件/改动的选区均可加入底部选择清单；已发布材料绑定整份固定版本，原文批注保留准确的 `target/quote`。允许跨类型、跨空间选择，切换页面和筛选不清空。菜单栏与浏览器通过同一个本机 Core 共享选择，收藏、最近使用记录与选择持久化到数据目录的 `library.json`，不复制材料正文或整个原生历史。正文分页与滚动位置只在当前资源库页面内记忆。

点击“生成读取入口”后，在底部选择栏内显示短编号与“复制读取提示”，不打开模态窗口，不锁定页面焦点。提示原文、固定的内容列表和有效期按需展开。关闭只收起界面；继续修改选择不会改变已生成编号，明确点击“重新生成”才取得新的编号。

个人 Agent 通过 `read_selection(code, offset?)` 读取编号绑定的明确引用。编号不绑定一个含糊的“当前选中”，也不根据最近活动推断个人 Session。它只在生成它的本机 Core 数据目录中有效，不是跨设备邀请或访问凭据。材料按指定版本读取；执行上下文仍是当前内容，Agent 需要重新核对原文。生成或读取入口不会自动回复批注或启动模型输入。接入个人 MCP 仍从“设置与连接”完成。

## 发到共享会话

选择全部来自同一空间时，可直接点击“发送到共享会话”，预览明确目标、所选引用和可编辑的处理要求，再确认发送。页面不增加统一的目标/意图选择流程，也不把保存批注改成发送任务。

首版发送只在目标有执行、在线、空闲、当前用户持有输入且 Provider 支持输入时可用；存在审批或原生等待时拒绝。Core 在发送前重新核对引用范围，实际输入继续走原有 RPC、输入归属与请求去重。跨空间选择只能生成个人读取入口。已提交、已接收与 `turn/completed` 分别显示；结果不明时引导查看会话，不自动重放。运行中补充和原生审批继续在现有客户端完成。

共享运行时内置 MCP 仍只有当前空间的四个批注/材料工具，不向其中增加个人 `read_selection`。信任模式继承用户已有个人 MCP 的既定边界不变。

## macOS 协作速览

左键点击菜单栏图标打开紧凑协作速览；`Control + Option + T` 注册成功后也可呼出。速览提供平级的“当前协作”和“资源速览”，首次打开默认显示当前协作，窗口存续期间保留所选视图。当前协作读取现有协作列表，显示未结束、未离开的空间，包含只读、执行、断线及需要处理的状态，可按发起者/参与者筛选并打开对应详情；切回该视图或窗口重新获得焦点时刷新状态。资源速览可搜索、筛选、收藏、选择并生成读取入口，切换到当前协作后保留搜索、筛选和选择，完整阅读在 WebGUI 中打开；可以固定为浮窗。

速览列表、空状态和展开的选择清单随同一页面滚动，不再为资源列表设置独立滚动高度；选择栏收起时贴近视口底部，展开清单或读取入口后进入正常页面布局并滚动到可见位置，长清单仍能完整滚动且不遮住列表操作。“服务与设置”与“最近使用”“我参与的”等筛选位于同一工具行，窄窗口和英文标签允许筛选自然换行。右键菜单栏图标或速览中的服务菜单保留打开页面、设置、服务状态、CLI 管理与退出等原有动作。热键冲突时仍可通过图标或菜单打开。

App 使用同源 `WKWebView` 呈现速览，原生桥只允许打开经过校验的本机资源路由、固定窗口和打开服务菜单，不提供任意命令或外部导航。速览复用原有 Core 启动发现、App 去重和退出规则。

## 限制与重新评估

首版不提供团队公共文件库、全文离线副本、自动同步私人 Session 或任意个人 Session 的自动输入绑定。只有能够可靠核对目标 Session 和所属用户时，才考虑进一步免除最后一次粘贴。资源量增大时再评估索引分页与全文搜索；当前收藏和导航元数据有数量界限，协议细节统一见 [资源库接口](../protocol.md#个人资源库)。
