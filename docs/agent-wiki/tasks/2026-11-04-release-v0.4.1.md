## Homebrew 验证修复

新版 Homebrew 检查其可执行文件是否受到继承沙箱保护。原验证脚本将整个隔离前缀放在 macOS 系统临时目录，而 Homebrew 允许写入这些临时目录，因此报 `Inherited sandbox permits writes`。本机带空格的仓库路径还触发了 Homebrew 子进程路径处理错误。

主仓库验证脚本改为在家目录下创建自动清理的隔离前缀，并允许 `--temp-root` 选择不含空白、位于系统临时目录之外的现有目录。保留 Homebrew 沙箱及原 Formula/Cask、升级、互斥、字节和卸载保留数据检查。修复后本机与 GitHub 构建阶段的检查均通过。

发布后的 tap PR 首轮遇到相同临时目录问题；在同一个 [Homebrew PR #14](https://github.com/YTwsy/homebrew-teamcross/pull/14) 修复独立 tap 验证器。修复提交 `37c7d11c1e060a54f56590455308fcace71fb97d` 的[必需检查](https://github.com/YTwsy/homebrew-teamcross/actions/runs/41823994889)通过后，按现有 squash 方式普通合并为 `b77efb10440c3864073e9030256c7c6bec9de80b`，未使用管理员绕过。只重跑发布流程失败的 Homebrew 阶段，既有 Release 资产与标签未重建或替换。

合并后的[公共 main 安装检查](https://github.com/YTwsy/homebrew-teamcross/actions/runs/41824686655)通过，稳定 Formula 与 Cask 均为 `0.4.1`。
