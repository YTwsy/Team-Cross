# 六项阅读体验实现与验证

2026-10-23，分支 `codex/reading-experience`，基于 `Meta` 的 `8bc8397`，本报告覆盖该分支中本次未提交的阅读器、Core 接口及嵌入资源差异。保留工作区原有的分身、顺流、成员活动设计文档，不纳入本次范围。

## 已实现范围

| 能力 | 行为与边界 |
| --- | --- |
| Mermaid / flowchart | 本地 Pele 渲染；图形/源码切换、展开、缩放、平移、错误回退。生成中的消息显示源码，完成后显示图形。可整块或切回源码批注；不做节点批注。 |
| 代码 | 语言标识、复制、换行、长代码展开、本地 Shiki 高亮。显示变化保留 UTF-16 原文位置；整块批注仍受既有 8000 字选区上限约束，较长内容可选取部分源码。 |
| 表格与公式 | 横向滚动、换行、复制 Markdown/CSV；本地 KaTeX MathML，无远程字体。搜索命中不可见 Markdown 语法或公式时自动显示原文。 |
| 图片 | 原生明确图片字段冻结为版本 CAS blob；按准确材料版本、轮次、消息和附件 ID 分块读取。预览、历史、材料共用缩略图、加载/失败状态、重试、查看器和同消息图片切换。批注绑定整张图片的原文标记。 |
| 阅读跟随 | 沿用现有轮询与序列号。到达底部后自动补齐当前历史页并跟随；上滚、选区、搜索、编辑和弹窗暂停跟随；回到最新后继续。固定材料不被新版本替换。 |
| 全文搜索 | 搜索整个可读会话或当前固定材料版本，包括未加载页；默认用户/助手正文，工具输出需显式启用。精确命中按 UTF-16 定位，展开折叠过程，关闭搜索恢复阅读位置；完成前不报告最终计数。每自动加载至少 1024 处命中暂停，由读者选择继续。 |

图片支持 PNG/JPEG/GIF/WebP，原始字节最多 6 MiB、每条消息最多 32 张，沿用版本唯一 blob 32 MiB、空间活动 blob 256 MiB 配额。外部 Markdown 图片只给占位及主动打开来源的入口，不自动抓取；普通文件附件未新增导出能力。实际原生图片字段范围见[读取协议](../../../sources/protocol.md#阅读器图片与全文搜索)。不改实时同步协议、重连补发或输入归属。

## 浏览器与 MCP 检查

使用 `TestReaderBrowserFixture`，20 轮合成原生历史、真实隔离 Core、固定版本材料、两个图片附件。普通浏览器与 `scripts/chatgpt-plugin-browser.py` 的 stdio MCP 业务接口真实执行；iframe 宿主握手为模拟，CSP 禁止 iframe 联网。fixture 对插件安装状态返回不可用，避免调用用户已安装的管理助手；这不验证插件安装流程。

- 普通页面验证图形/源码、展开缩放、图片 1/2 切换及缩放复位；保存整图、流程图整块、源码 `flowchart LR` 选区批注，原文和版本正确。
- 材料搜索工具输出后自动加载并展开过程；协作会话搜索 `SEARCH-OLDER-01`，跨越未加载历史页并显示原文高亮。
- 插件在禁止 iframe 联网的 CSP 下显示图形、2 张图片、2 处公式；125% 缩放成功，全文搜索定位表格原文。
- 1440 像素浅色中文、英文深色图形、768 像素英文深色阅读布局已截图复核；768 窗口中文档宽度 753，无页面横向溢出。额外 480 像素布局未单列验收。
- 最终构建的“回到最新”补齐到最新轮；合成 `inProgress` 更新自动出现。上滚后再次追加并完成，原显示正文不变，出现新内容提示；点击回到最新显示两次追加并重新渲染图形。该轮浏览器控制台 0 errors / 0 warnings。

首轮插件 harness 因其 30 秒 RPC 等待短于安装状态助手调用而错位；定位到 `plugin/connection` 后隔离该依赖重验通过。它不是本次实时同步功能的验收结论。源码选区自动化先滚动到可见行再选择，避免对屏幕外文字的合成选区误判浮条。

收尾复查补齐后续正文片段的图片元数据合并，避免长消息中位于后续分页的附件漏显；对应回归检查合并、去重及不修改已有片段，并重跑 Web 全量门槛与两套资源构建。此前截图不作为这一特殊分页分支的证据。

## 结论边界

原生历史为合成 fixture，没有调用真实模型，不是两台 Mac、真实 Codex/ChatGPT 宿主、Cloud 或 Claude 图片格式验收。Pele 识别多种图形，本轮实际浏览器验收以 flowchart 为主，不保证所有 Mermaid 语法与布局完全一致。原图保存与访问隔离由 Core 回归和跨 Core 本机测试支持；现有真实网络或原生客户端证据不自动扩展到本次六项展示。
