## 完成范围

- 空间工作台提供阅读与讨论、协作请求、空间简报、参与会话；材料正文和阅读旁栏可就地发起。复用原材料、批注、配对、发送和分阶段回执组件。
- 成员在自己的 Core 明确关联接收目标；空间内共享请求、固定版本来源、父请求关联和结果。普通 MCP 会话与专用会话使用同一套通用查询/发送工具。
- 主机校验实际成员凭据，本机工具核对原生调用者。私人配对与历史不公开；只接受本空间已发布材料/公开批注。共享执行目标仍校验当前输入权和执行访问。
- 空间简报由成员确认保存，来源可定位，版本冲突拒绝覆盖并保留界面草稿。
- 每空间零个或一个可选专用角色；启动包含空间/角色身份、确认简报、公开目录、目标、待处理请求和规则。先读取再报告接手；暂停、停用、更换及晚到结果保持明确归属。
- 新增显式独立 Codex 接收会话，使用原生新 Session 与专用目录，不 fork、不创建共同执行。重启后保留原生 ID，显式恢复，不自动投递。产品继承原生模型设置。
- 修复收尾过程中发现的 Core 退出竞争：待分享任务在关闭边界同步取消，避免记录为偶发的普通失败；活动独立接收会话纳入退出状态计数。
