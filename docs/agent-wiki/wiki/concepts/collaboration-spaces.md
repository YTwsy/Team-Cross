# 只读分享与多人协作空间

空间把成员、已发布材料和讨论组织在一起，可以独立于共同执行存在。材料的固定版本
提供可引用的共同原文；个人会话的后续内容和执行现场各有自己的公开边界。

| 关系 | 所解释的边界 |
| --- | --- |
| 成员与空间 | 谁参与这次协作 |
| 材料与来源会话 | 哪一份已公开内容成为共同依据 |
| 空间与多个协作会话 | 一个空间组织多个独立原生 fork 与执行现场 |
| 成员与协作会话 | 所有成员共同读取各会话历史和执行现场，按会话申请输入 |
| 当前输入者与共享会话 | 谁此刻负责模型输入与操作 |

空间请求连接明确关联的接收目标，简报保存成员确认的议题与决定，可选专用会话承担协调
角色。空间统一保存成员与公开材料，全部空间成员共同读取所有协作会话，每个会话分别管理输入者和生命周期。暂停或结束一个会话的执行不影响读取与兄弟会话；关闭空间才结束全部远端参与。个人原生来源只有明确发布的材料或新建协作 fork 成为共享内容。
