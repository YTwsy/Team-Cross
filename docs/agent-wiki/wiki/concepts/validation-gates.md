# 验证与证据

验证契约回答怎样检查、什么算通过；执行记录回答哪个版本在什么环境实际发生了什么；
证据入口把这些记录与当前路径关联，帮助判断结果仍能适用到哪里。

构建和自动化用例、浏览器界面、原生客户端与模型处理、跨机网络各自提供不同层面的
证据。原生平台能力、Team Cross 的接入范围和被测环境分别判断；同机多个 Core 的结果
不能扩展为多台 Mac 的网络结论，工具调用成功也不等于目标会话已处理。

最近已知结果与当前 checkout 是否复验是两个问题。证据需要绑定版本、路径和环境；
未收录或未检索到报告，也不直接构成不支持的结论。

- 选择命令、通过标准、客户端与网络检查 → [验证门槛](../../sources/validation/test-gates.md)。
- 判断已有结果及其当前适用性 → [证据入口](../../sources/validation/evidence-map.md)。
- 查询发布与安装各阶段的成功条件 → [构建与发布](../../sources/releasing.md)。
- 保存本次结果或定向追溯历史 → [任务记录与检索规则](../../README.md#任务记录)。
