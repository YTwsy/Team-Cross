# 验证与验收导航

本页帮助选择证据层次。要确定当前应执行哪些检查，读 [验证门槛](../../sources/validation/test-gates.md)；要回答某条路径是否验收过，从 [验证范围与证据入口](../../sources/validation/evidence-map.md) 定位具体报告。方法、已知结果和本次执行记录分别维护。

| 证据 | 能支持的判断 |
| --- | --- |
| 构建、类型检查与静态检查 | 当前代码与资源可编译，未代替运行时验证 |
| 单元、集成与 race test | 覆盖对应自动化用例中的逻辑和并发路径，模拟运行时不代表真实模型 |
| 真实浏览器与截图 | 页面流程、状态和视觉表现，未代替原生客户端执行 |
| 原生工具加载与协议调用 | 对应宿主版本能加载或调用工具，未代替成品桌面交互或模型处理 |
| 专用 TUI/Desktop 与原生运行时 | 对应版本、入口和测试目录中的真实行为 |
| 同机多个 Core 或客户端 | 本机多成员流程，未证明跨设备网络 |
| 两台 Mac 的 LAN 或跨网络 | 实际执行过的设备、传输与网络条件，不能互相替代 |
| 公开 Release 与 Homebrew 安装 | 对应版本的发布与安装结果，未证明 Apple 公证或新功能的真实模型行为 |

发布步骤与各阶段的成功条件见 [构建与发布](../../sources/releasing.md)。CI、发布流水线、真实模型、宿主桌面和跨机联网检查分别选择与报告，不能从一个阶段成功补出其他阶段的结论。

## 本次结果与历史记录

小改动在提交或 PR 中说明实际检查即可；跨会话调查、多环境验证或需要交接时，再按 [任务记录规则](../../README.md#任务记录) 保存报告。记录日期、被测版本、环境、结果、证据位置及未覆盖项。

回答验收问题时，先明确 Provider、目标会话、客户端、接收方式和网络环境，再由证据入口读取相应报告。最近已知通过不等于当前版本已复验；后续改动影响该路径时，补充适用边界。没有收录或未检索到结果，也不能直接判断不支持或没有测试。

已结束记录默认不搜索或批量读取，确有问题时定向追溯。可复用方法或通过标准变化时更新验证门槛；已知覆盖范围、阻塞或旧证据适用性变化时更新证据入口。概念页只在证据层次或阅读方式变化时更新。

## 交付时记录

分别报告工程检查、浏览器检查和真实客户端检查，标明实际版本、环境及未覆盖范围。真实模型只使用专用 Luna 会话和仓库；验证后精确关闭本次测试客户端、Core、app-server、浏览器和残留辅助进程。具体执行要求由 [验证门槛](../../sources/validation/test-gates.md) 维护。

仅整理文档时检查链接、旧引用、代码路径和索引可达性，不重复启动运行时，也不因此把旧报告标记为本次通过。
