# Team Cross v0.2.5

`v0.2.5` 是面向 Apple Silicon、macOS 14 及以上的正式版本。相比 `v0.2.4`，本版让菜单栏速览先呈现正在参与的协作，并为菜单栏和 WebGUI 增加共用的中英文界面语言选择。

## 主要变化

- 菜单栏速览新增“当前协作”，与“资源速览”平级切换，默认打开当前协作。可按发起或加入筛选并进入对应协作；已结束和已离开的空间不再占用当前列表，断线和需要处理的协作仍保留。
- 资源速览改为随页面统一滚动，展开选择清单或读取入口后也不再出现页面内嵌套滚动。“服务与设置”移到与资源分组同一行；搜索、筛选和已选内容在两种速览之间切换时保留。
- 菜单栏与 WebGUI 共用本机界面语言偏好，默认跟随 macOS 首选语言；中文语言代码显示简体中文，其他语言显示英文。可从任一界面选择“跟随系统 / 简体中文 / English”，另一界面同步更新。会话原文、材料、用户输入和协议字段不翻译。
- 菜单栏服务菜单跟随 App 当前外观，支持系统、浅色和深色主题。

## 安装与升级

- **App**：下载 [Apple Silicon DMG](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.5/Team-Cross-0.2.5-arm64.dmg)，将 `Team Cross.app` 拖入“应用程序”并打开。
- **独立 CLI**：下载 [arm64 CLI](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.5/teamcross-0.2.5-darwin-arm64.tar.gz)，解压后将 `teamcross` 放入自己的 `PATH` 目录。

稳定 Homebrew Formula 与 Cask 会在公开 Release 资产完成复核后由后续发布阶段更新。Release 页面出现自动写入的 Homebrew 小节后，才表示对应稳定通道已完成公共 tap 安装验证。

升级前退出正在运行的 Team Cross，通过原安装渠道更新。协作数据与工作目录保留；旧 `schema:2` 材料仍保留在磁盘，但本版不加载或迁移它们。

安装包使用 **ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证**。首次打开若受到 macOS 提示，请先尝试打开 App，再到“系统设置 → 隐私与安全性”中确认。

## 验证与当前范围

中英文界面经过消息完整性检查、Web 交互测试与浏览器复核。协作速览通过 Go test/vet、相关 race test、126 项 Web 测试、生产构建与 Swift 编译；在中英文、深浅主题和弹窗/浮窗尺寸下复核了 26 个浏览器视图、滚动与主要操作。详细记录见[状态栏协作速览](https://github.com/YTwsy/Team-Cross/blob/v0.2.5/docs/agent-wiki/sources/validation/quicklook-navigation-2026-09-24.md)。

Tag 发布流水线会从本版提交重新运行工程门槛、arm64 CLI/App/DMG 构建、安装与生命周期、Homebrew 隔离安装、校验和与构建来源证明检查。本次没有新增真实模型、两台 Mac LAN、跨网络 Tailcat 或持续 DERP 验收；Claude Code 原生 TUI 与 Tailcat 继续保持实验性。

可用 [SHA256SUMS](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.5/SHA256SUMS) 校验资产，并从 [release.json](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.5/release.json) 核对版本、来源提交、架构与签名状态。使用方法见[使用指南](https://github.com/YTwsy/Team-Cross/blob/v0.2.5/docs/user-guide.md)。
