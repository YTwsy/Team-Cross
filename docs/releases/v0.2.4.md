# Team Cross v0.2.4

`v0.2.4` 是面向 Apple Silicon、macOS 14 及以上的正式补丁版本，修复协作详情短页面反复上下跳动的问题。

## 修复内容

- 修复材料较少、正文尚未展开时，滚动到页面下方会触发“参与成员”反复收起与展开的问题；已关闭空间同样适用。
- 自动折叠期间保持页面可滚动范围稳定，回到概览后恢复展开。保留手动展开、焦点保护、窄屏布局和减少动态效果支持。
- 切换长正文与短材料列表时，预留高度只依据右栏实际内容，避免留下大段空白。

## 安装与升级

- **App**：下载 [Apple Silicon DMG](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.4/Team-Cross-0.2.4-arm64.dmg)，将 `Team Cross.app` 拖入“应用程序”并打开。
- **独立 CLI**：下载 [arm64 CLI](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.4/teamcross-0.2.4-darwin-arm64.tar.gz)，解压后将 `teamcross` 放入自己的 `PATH` 目录。

稳定 Homebrew Formula 与 Cask 会在公开 Release 资产完成复核后由后续发布阶段更新。Release 页面出现自动写入的 Homebrew 小节后，才表示对应稳定通道已完成公共 tap 安装验证。

升级前退出正在运行的 Team Cross，通过原安装渠道更新。协作数据与工作目录保留；旧 `schema:2` 材料仍保留在磁盘，但本版不加载或迁移它们。

安装包使用 **ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证**。首次打开若受到 macOS 提示，请先尝试打开 App，再到“系统设置 → 隐私与安全性”中确认。

## 验证与当前范围

本地 Web check、122 项测试、生产构建及 Go test/vet、相关 race test 通过。Edge 复核了原问题、三种窗口宽度、深浅主题与减少动态效果；连续采样未再出现反复收放和滚动位移。详细记录见[短页面成员折叠稳定性](../agent-wiki/sources/validation/member-fold-stability-2026-09-23.md)。
