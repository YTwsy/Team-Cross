# Team Cross v0.1.6-rc.1

`v0.1.6-rc.1` 是面向 Apple Silicon、macOS 14 及以上的预发布版本。本次加入显式的 Tailcat 跨网络协作选项，并把 GitHub 上的工程检查、安装验证、校验和与构建来源证明串成可重复的发布链路。会话、模型调用与代码执行仍保留在发起者的 Mac。

## 安装

- **App**：下载 [DMG](https://github.com/YTwsy/Team-Cross/releases/download/v0.1.6-rc.1/Team-Cross-0.1.6-rc.1-arm64.dmg)，将 `Team Cross.app` 拖入“应用程序”并打开。
- **独立 CLI**：下载 [arm64 CLI](https://github.com/YTwsy/Team-Cross/releases/download/v0.1.6-rc.1/teamcross-0.1.6-rc.1-darwin-arm64.tar.gz)，解压后将 `teamcross` 放入自己的 `PATH` 目录。

本预发布包使用 ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证。首次打开若受到 macOS 提示，请先尝试打开 App，再到“系统设置 → 隐私与安全性”中确认。

Homebrew tap 是 Release 之后的独立发布步骤，本次预发布不更新公共 Formula 或 Cask；`YTwsy/teamcross` 仍指向此前已发布的版本。

## 主要变化

- 创建与重新邀请协作时明确选择“局域网”或实验性的“Tailcat”，不自动探测、回退或暗中切换连接方式。
- 新的 `tcx3` 邀请格式在 LAN 地址与 Tailcat 参数之间保持互斥，同时继续使用 TLS 1.3、SPKI 指纹、一次性首次加入和独立成员凭据。
- Tailcat 通过 DERP 完成发现和初始连接，网络允许时可使用点对点 UDP，否则可继续经 DERP 中继；页面会显示实际选择，并明确整份邀请码需要按秘密处理。
- 完善 Tailcat 启动失败、取消、重连和资源关闭路径，并覆盖共享层成员重连、协作状态、输入交接和直接客户端 WebSocket 桥接。
- 调整 macOS App 图标的视觉居中，并修复命令行启动器并发安装/移除时的状态检查竞态。
- 新增 GitHub CI 与 unsigned macOS release workflow；发布产物经过工程门槛、DMG/App/CLI 安装与生命周期、隔离 Homebrew、SHA-256 和 SLSA provenance 验证后才会创建 Release。

## 当前范围

项目仍处于原型阶段，当前只提供 arm64 产物；Intel、自动更新和登录自启尚未提供。Tailcat 仍是实验性连接方式：本轮实网回归来自同一台 Mac 上的两套隔离 Core，不能证明两台物理 Mac、不同 NAT、受限 UDP、持续 DERP 中继、睡眠或网络切换恢复已经验收。公共 DERP 的长期可用性和性能也不由一次发布保证。

tag 发布流水线会在对应提交上重新执行 Go test/vet、相关 race test、Web check/test/build、嵌入资源一致性、arm64 构建、DMG/App/CLI 安装与生命周期，以及隔离 Homebrew 安装，并为 CLI tar 与 DMG 生成校验和和构建来源证明。它不运行真实模型、两台 Mac 网络或公开 Homebrew tap 验收。

下载校验值见 [SHA256SUMS](https://github.com/YTwsy/Team-Cross/releases/download/v0.1.6-rc.1/SHA256SUMS)，版本、来源提交与签名状态见 [release.json](https://github.com/YTwsy/Team-Cross/releases/download/v0.1.6-rc.1/release.json)。使用方法见 [README](../../README.md)。
