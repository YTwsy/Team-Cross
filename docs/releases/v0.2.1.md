# Team Cross v0.2.1

`v0.2.1` 是面向 Apple Silicon、macOS 14 及以上的正式稳定版本。本版将 `v0.2.1-rc.1` 中的内容寻址材料与按需阅读能力纳入稳定渠道，并补齐面向使用者的安装、操作和开发指南。

## 主要变化

- 已发布材料使用 `schema:3`：空间保存版本元数据，不可变清单与正文按内容哈希存储。发布先协商、上传缺失正文，最后提交版本引用；旧 `schema:2` 材料保留在磁盘，但本版不加载或迁移。
- 阅读材料时，长工具输出默认显示精确前缀和总长度；可按 `turnId + itemId + startOffset` 继续读取单条内容。个人 MCP 也可按条读取本机私有冻结草稿。
- 对话目录可以定位当前页尚未加载的轮次，按需读取后跳转；阅读工具栏显示版本来源、提供方、公开轮次与导出说明。
- 发起页明确区分“先分享讨论”和“直接一起执行”；只读分享不创建原生 fork，也不开放执行目录。
- 新增独立的[使用指南](../user-guide.md)与[开发和验证指南](../development.md)，根目录 README 聚焦产品概览、安装和快速开始。

## 安装

- **App**：下载 [Apple Silicon DMG](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.1/Team-Cross-0.2.1-arm64.dmg)，将 `Team Cross.app` 拖入“应用程序”并打开。
- **独立 CLI**：下载 [arm64 CLI](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.1/teamcross-0.2.1-darwin-arm64.tar.gz)，解压后将 `teamcross` 放入自己的 `PATH` 目录。

稳定 Homebrew Formula 与 Cask 会在公开 Release 资产完成复核后由后续发布阶段更新。只有 Release 页面出现自动写入的 Homebrew 小节，才表示对应稳定通道已完成公共 tap 安装验证；在此之前可使用上面的直接下载。

安装包使用 **ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证**。首次打开若受到 macOS 提示，请先尝试打开 App，再到“系统设置 → 隐私与安全性”中确认。升级前退出正在运行的 Team Cross，通过原安装渠道更新；升级保留协作数据与工作目录。

## 验证与当前范围

Tag 发布流水线会在发布提交上重新运行 Go/Web 工程门槛、arm64 CLI/App/DMG 构建、App/CLI 生命周期和 Homebrew 隔离安装验证，并复核校验和与构建来源证明。先前功能验收证据见[内容寻址材料与按条读取](../agent-wiki/sources/validation/content-addressed-materials-2026-09-20.md)和[协作对话目录定位](../agent-wiki/sources/validation/context-outline-2026-09-20.md)；这些记录只对应其注明的提交、设备与测试边界，不能替代本 tag 的流水线结果。

本版当前仅提供 arm64 产物；Claude Code 原生 TUI 与 Tailcat 连接仍为实验性。上述同机与浏览器验收不代表真实模型、两台 Mac LAN、跨网络 Tailcat 或持续 DERP 的新验收。

发布后可从 [SHA256SUMS](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.1/SHA256SUMS) 校验资产，从 [release.json](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.1/release.json) 核对版本、来源提交、架构与签名状态。使用方法见[使用指南](../user-guide.md)。
