# Team Cross v0.2.1-rc.1

`v0.2.1-rc.1` 是面向 Apple Silicon、macOS 14 及以上的预发布版本。本版在 `v0.2.0-rc.1` 的只读材料工作区之上，把材料正文改成内容寻址存储，并让阅读页能按条展开长工具输出、从目录定位尚未加载的轮次。

## 相对 v0.2.0-rc.1 的变化

- 已发布材料改为 `schema:3`：空间记录只保留版本元数据，不可变清单和大正文分别按内容哈希保存。远端发布先协商、再上传缺失正文、最后提交；协商只复用当前作者自己未撤回版本中的内容。旧 `schema:2` 原样留盘但不加载。
- 默认阅读流完整返回对话，超过阈值的工具输出只显示精确前缀和总长度。材料和活协作历史可用同一套 `turnId + itemId + startOffset` 按条继续读取，游标不跨到其他条目。
- 个人 MCP 增加 `read_publication_draft`，按同样方式读取本机私有冻结草稿；共享运行时仍只有当前空间的四个工具。
- 协作对话目录可以定位尚未出现在当前页的轮次：已加载的直接滚动，未加载的先读取再定位，并保留专注阅读选择。
- 材料阅读工具栏改为版本选择与来源摘要，窄屏也能看清提供方、公开轮次和导出说明；展开后的按钮与“收起正文”一致，显示为“收起材料”。
- 发起页用卡片区分“先分享讨论”和“直接一起执行”，来源客户端只作为会话列表筛选，并与首页共用同一栏宽；切换形态、来源或首页筛选时不再把页面撑歪或上下跳动。

## 安装

- **App**：下载 [DMG](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.1-rc.1/Team-Cross-0.2.1-rc.1-arm64.dmg)，将 `Team Cross.app` 拖入“应用程序”并打开。
- **独立 CLI**：下载 [arm64 CLI](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.1-rc.1/teamcross-0.2.1-rc.1-darwin-arm64.tar.gz)，解压后将 `teamcross` 放入自己的 `PATH` 目录。

本预发布包使用 ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证。首次打开若受到 macOS 提示，请先尝试打开 App，再到“系统设置 → 隐私与安全性”中确认。升级前请退出正在运行的 Team Cross，通过原安装渠道更新；升级保留协作数据和工作目录。

GitHub Release 创建后，同一 tag 的受保护 Homebrew 阶段会复核公开资产、构建来源与隔离安装，再通过独立 tap PR 发布 `teamcross-rc` 和 `team-cross@rc`。只有 Release 页面出现自动写入的 Homebrew 小节后，才表示公共 RC tap 已通过安装验证；在此之前可使用上述直接下载。RC 使用显式独立通道，不会把稳定安装者自动带到候选版。

## 验证与当前范围

内容寻址存储与按条读取验收在 macOS 14.8.5 / arm64、Go 1.27.1、pnpm 11.19.0 上完成，包含 Go test/vet、相关 race test、Web 类型检查、83 项 Web 测试、生产构建，以及三个本地 Core 的浏览器闭环。详细证据见 [内容寻址材料验收](../agent-wiki/sources/validation/content-addressed-materials-2026-09-20.md)。目录定位随后在同一基线上通过工程门槛和 86 项 Web 回归，并完成源码预览下的截图复核；用户要求停止后未再追加浏览器闭环，见 [协作对话目录定位](../agent-wiki/sources/validation/context-outline-2026-09-20.md)。材料阅读工具栏与展开文案另有 Web 回归，本机安装校验通过，不构成新的浏览器验收。

本轮浏览器与 Core 使用合成历史和测试替身，不是新的真实模型、原生 TUI/Desktop、两台 Mac LAN、跨网络 Tailcat 或持续 DERP 验收。当前只提供 arm64 产物，尚无 Intel、自动更新或登录自启；Claude Code 接入仍为实验性。tag 流水线会在发布提交上重新执行工程门槛、arm64 CLI/App/DMG 构建、安装与生命周期检查、隔离及公共 Homebrew 安装、SHA-256 和构建来源证明。

下载校验值见 [SHA256SUMS](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.1-rc.1/SHA256SUMS)，版本、来源提交与签名状态见 [release.json](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.1-rc.1/release.json)。使用方法见 [README](https://github.com/YTwsy/Team-Cross/blob/v0.2.1-rc.1/README.md)。
