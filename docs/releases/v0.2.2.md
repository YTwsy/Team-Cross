# Team Cross v0.2.2

`v0.2.2` 是面向 Apple Silicon、macOS 14 及以上的正式稳定版本。本版让个人资源库与材料选择进入稳定渠道，并重新整理协作详情中的材料、上下文、邀请和阅读操作，减少重复信息与页面跳动。

## 主要变化

- 新增个人资源库，按 Session 汇集已发布材料、批注、回复和获准的协作上下文；支持搜索、筛选、收藏、固定版本阅读和返回原文位置。
- 可跨类型加入选择并生成固定的 `TC-…` 本机读取编号，供个人 Agent 按需读取；同一空间的选择可预览后发送给共享会话，每次读取都会重新检查当前权限与撤回状态。
- macOS 菜单栏增加资源速览和 `Control + Option + T` 快捷键；原有右键服务菜单及 WebGUI“设置与连接”入口继续保留。
- 协作详情在同一阅读面板中切换“已发布会话材料”和“协作上下文”，分别保留阅读位置、分页、已展开工具过程和专注状态。
- 点击“阅读材料”后，正文直接在对应材料卡片内展开；版本、来源、选择、收藏、Agent 阅读提示和作者操作集中在卡片顶部，不再重复显示标题和工具栏。切换历史版本时，标题、公开轮数和操作同步绑定当前固定版本。
- 邀请连接方式改为更清晰的局域网与实验性 Tailcat 选择卡片，同时保持已有连接和权限边界。

## 安装

- **App**：下载 [Apple Silicon DMG](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.2/Team-Cross-0.2.2-arm64.dmg)，将 `Team Cross.app` 拖入“应用程序”并打开。
- **独立 CLI**：下载 [arm64 CLI](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.2/teamcross-0.2.2-darwin-arm64.tar.gz)，解压后将 `teamcross` 放入自己的 `PATH` 目录。

稳定 Homebrew Formula 与 Cask 会在公开 Release 资产完成复核后由后续发布阶段更新。只有 Release 页面出现自动写入的 Homebrew 小节，才表示对应稳定通道已完成公共 tap 安装验证；在此之前可使用上面的直接下载。

安装包使用 **ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证**。首次打开若受到 macOS 提示，请先尝试打开 App，再到“系统设置 → 隐私与安全性”中确认。升级前退出正在运行的 Team Cross，通过原安装渠道更新；升级保留协作数据与工作目录。

## 验证与当前范围

Tag 发布流水线会在发布提交上重新运行 Go/Web 工程门槛、arm64 CLI/App/DMG 构建、App/CLI 生命周期和 Homebrew 隔离安装验证，并复核校验和与构建来源证明。功能验收证据见[个人资源库与资源速览](../agent-wiki/sources/validation/resource-library-2026-09-22.md)、[协作阅读布局与操作反馈](../agent-wiki/sources/validation/reading-tabs-2026-09-22.md)和[材料卡片内阅读](../agent-wiki/sources/validation/material-cards-2026-09-22.md)；这些记录只对应其注明的提交、设备与测试边界，不能替代本 tag 的流水线结果。

本版当前仅提供 arm64 产物；菜单栏热键呼出和固定浮窗的真实桌面交互仍未单独完成电脑控制验收。Claude Code 原生 TUI 与 Tailcat 连接仍为实验性。上述同机、浏览器和本地安装验证不代表真实模型、两台 Mac LAN、跨网络 Tailcat 或持续 DERP 的新验收。

发布后可从 [SHA256SUMS](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.2/SHA256SUMS) 校验资产，从 [release.json](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.2/release.json) 核对版本、来源提交、架构与签名状态。使用方法见[使用指南](../user-guide.md)。
