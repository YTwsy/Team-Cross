# Team Cross v0.1.1

Team Cross 的首个公开版本，让同事通过自己的 Codex 客户端，一起继续一个已有的原生 Codex 会话。会话与代码执行保留在发起者的 Mac。

## 安装

支持 Apple Silicon、macOS 14 及以上。选择一种安装方式：

- **App**：下载 [DMG](https://github.com/YTwsy/Team-Cross/releases/download/v0.1.1/Team-Cross-0.1.1-arm64.dmg)，将 `Team Cross.app` 拖入“应用程序”并打开。在菜单栏选择“命令行工具…”后，终端也可运行 `teamcross`。
- **Homebrew App**：`brew install --cask YTwsy/teamcross/team-cross`，同时安装 App 和 `teamcross` 命令。
- **Homebrew CLI**：`brew install YTwsy/teamcross/teamcross`，只安装命令行入口；运行 `teamcross` 打开协作空间。
- **独立 CLI 文件**：下载 [arm64 CLI](https://github.com/YTwsy/Team-Cross/releases/download/v0.1.1/teamcross-0.1.1-darwin-arm64.tar.gz)，解压后将 `teamcross` 放入自己的 PATH 目录。

运行时不需要 Go、Node 或 pnpm。App 自带完整 CLI，Formula 与 Cask 为互斥的安装方式。切换前退出服务并卸载旧渠道；Formula 升级可能保留旧版本，切换时使用 `brew uninstall --formula --force teamcross`。卸载保留会话、协作数据和工作目录。

首次打开受到 macOS 提示时，先尝试打开 App，再按 [Apple 的说明](https://support.apple.com/zh-cn/102445)，在“系统设置 → 隐私与安全性”中允许打开。

## 这个版本可以做什么

- 从来源会话创建新的 Codex fork，选择保留原目录的当前现场，或从选定 HEAD 创建独立 worktree。
- 通过邀请预览后加入协作；首次加入期限与加入后的持续访问资格分开管理。
- 查看历史、代码改动、文件和批注；申请输入、明确交接与接回，所有写入入口共享输入归属。
- 使用本机 TUI、专用 Desktop，或让自己的 Codex 通过本地 MCP 辅助。模型与推理设置继承原生会话，后续遵循当前输入者的选择。
- 从 App、CLI、MCP 复用同一个本机 Core。版本升级不自动中断活动协作；设置页显示安装位置及已安装、运行中的版本。
- 结束共享后，在当前执行和客户端连接结束时释放原生会话占用，保留工作成果与原生历史。

## 当前范围

项目仍处于原型阶段。当前提供 Apple Silicon 安装包；Intel、自动更新和登录自启尚未提供。原生客户端使用 Codex 的实验接口，其他版本和 Desktop 全局功能不在当前兼容承诺中。

已完成工程检查、隔离安装升级验证、浏览器复核及同机真实 Luna 运行时回归。两台 Mac 的 LAN、防火墙与睡眠恢复，以及完整原生窗口和首次系统批准流程，仍需补充实际验收；同机测试不代表这些检查已完成。详细环境与覆盖见 [本轮验收记录](../agent-wiki/sources/validation/distribution-v0.1.1-2026-09-11.md)。

下载校验值见 [SHA256SUMS](https://github.com/YTwsy/Team-Cross/releases/download/v0.1.1/SHA256SUMS)，版本、来源提交与构建状态见 [release.json](https://github.com/YTwsy/Team-Cross/releases/download/v0.1.1/release.json)。使用方法见 [README](../../README.md)。
