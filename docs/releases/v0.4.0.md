# Team Cross v0.4.0

本版重点是本机数字分身、连续协作和后台工作。

- **在空间中与数字分身协作。** 创建运行在自己 Mac 上的 Codex 分身，全体成员都能参与共享聊天；连续输入保留各自的作者、来源和回复关系，也可以通过显式 @ 自己把问题交给默认分身。
- **后台工作不挡住聊天。** 较长工作在独立 Work 会话中执行，主会话继续接收消息；分身可在执行中汇报进度，并把答复和结果送回原聊天、讨论或已绑定的发起会话。
- **看清会话、任务与记忆。** 新面板直接展示 S1、W1 等会话、实际上下文用量、任务进展与结果；任务提问支持“未结束任务 / 全部记录”筛选。
- **更完整的空间阅读与动态。** 一个空间支持多个协作会话共同阅读，改进长会话浏览、过程折叠与侧栏滚动；成员动态集中呈现 @、回复和关注更新，并区分人的已读与分身处理状态。
- **更顺畅的升级体验。** 改进 Core 升级与插件连接恢复，刷新插件界面时保留未发送草稿，减少旧资源版本造成的打开失败。

**已知限制：** 普通关注更新仍可能因来源引用校验失败而停在“处理需要核对”，后续更新可能排队；这不代表关注内容已处理完成。直接 @ 和共享聊天使用独立的直接输入路径。

安装范围为 Apple Silicon、macOS 14 及以上。产物使用 **ad-hoc 签名，未使用 Developer ID 签名，未经过 Apple 公证**。本版不新增两台 Mac 或跨网络 Tailcat 的验收结论。

## English

This release focuses on local digital shadows, continuous collaboration, and background work.

- Create a Codex shadow on your Mac and chat with it across the space. Consecutive inputs retain their authors, sources, and reply targets; explicitly mentioning yourself delegates to your default shadow.
- Run longer work in independent Work sessions while the main conversation continues. Progress and results return to the original chat, discussion, or bound originating session.
- Inspect S1/W1 sessions, reported context usage, task progress, results, and memory. Filter task questions by unfinished tasks or all records.
- Read multiple collaboration sessions in one space, with improved long-conversation navigation and activity views for mentions, replies, and followed updates.
- Improve Core upgrades and plugin recovery, preserving unsent drafts when refreshing the plugin interface.

**Known limitation:** ordinary followed updates can fail source-reference validation and leave later updates queued. Direct mentions and shared chat use a separate direct-input path.

For Apple Silicon Macs running macOS 14 or later. Packages use **ad-hoc signing without Developer ID signing or Apple notarization**. This release adds no new two-Mac or cross-network Tailcat acceptance claims.
