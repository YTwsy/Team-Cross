# Team Cross v0.2.0-rc.1

`v0.2.0-rc.1` 是面向 Apple Silicon、macOS 14 及以上的预发布版本。本版把只读协作空间推进为可持续阅读和讨论的材料工作区：成员可以发布多份固定版本材料，在原文中定位、批注并引用其他材料，而不需要启动模型或开放执行权限。

## 相对 v0.1.7-rc.1 的变化

- 支持独立只读空间、多人加入、固定范围的会话材料和材料版本；材料发布、更新、撤回与引用继续由 Core 校验，不会把正在进行的新对话自动公开。
- 已发布材料与协作上下文共用 Markdown/GFM 阅读器，支持列表、表格、引用、链接、本地 Shiki 代码高亮、轮次目录、工具过程折叠、原文切换和专注阅读。
- WebGUI 支持页面分页阅读、阅读位置缓存和新内容提示；读取仍由读者主动触发，撤回后停止新的正文读取，已保存的固定版本引用不被改写。
- 选区会映射回原始 UTF-16 偏移，覆盖 Markdown 实体、转义、emoji、行内代码和围栏代码；无法可靠映射时保留原文切换，不用相同文本搜索猜测位置。
- 对话和代码支持响应式原文旁批注卡，窄屏在消息下方展开；批注草稿、保存失败重试、讨论入口和单层回复保持在当前详情页内，不自动向共享 Agent 发送输入。
- 批注与回复可以按标题或作者搜索并引用材料的固定版本；默认只展示元数据，点击预览才读取正文片段，后续发布新版本不会替换已有引用。

## 安装

- **App**：下载 [DMG](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.0-rc.1/Team-Cross-0.2.0-rc.1-arm64.dmg)，将 `Team Cross.app` 拖入“应用程序”并打开。
- **独立 CLI**：下载 [arm64 CLI](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.0-rc.1/teamcross-0.2.0-rc.1-darwin-arm64.tar.gz)，解压后将 `teamcross` 放入自己的 `PATH` 目录。

本预发布包使用 ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证。首次打开若受到 macOS 提示，请先尝试打开 App，再到“系统设置 → 隐私与安全性”中确认。升级前请退出正在运行的 Team Cross，通过原安装渠道更新；升级保留协作数据和工作目录。

GitHub Release 创建后，同一 tag 的受保护 Homebrew 阶段会复核公开资产、构建来源与隔离安装，再通过独立 tap PR 发布 `teamcross-rc` 和 `team-cross@rc`。只有 Release 页面出现自动写入的 Homebrew 小节后，才表示公共 RC tap 已通过安装验证；在此之前可使用上述直接下载。RC 使用显式独立通道，不会把稳定安装者自动带到候选版。

## 验证与当前范围

本轮材料阅读与原文旁批注验收在 macOS 14.8.5 / arm64、Go 1.27.1、pnpm 11.19.0 和 Codex 内置 Chromium 上完成。Go test/vet、相关 race test、Web 类型检查、79 项 Web 测试和生产构建均通过；浏览器 fixture 覆盖 1440、1024、768 CSS 像素的浅色/深色阅读、UTF-16 选区、响应式批注、固定版本材料引用和三个本地 Core。详细证据见 [材料阅读与原文旁批注验收](../agent-wiki/sources/validation/reading-and-annotations-2026-09-19.md)。

本轮浏览器与 Core 使用合成历史和测试替身，不是新的真实模型、原生 TUI/Desktop、两台 Mac LAN、跨网络 Tailcat 或持续 DERP 验收。当前只提供 arm64 产物，尚无 Intel、自动更新或登录自启；Claude Code 接入仍为实验性。tag 流水线会在发布提交上重新执行工程门槛、arm64 CLI/App/DMG 构建、安装与生命周期检查、隔离及公共 Homebrew 安装、SHA-256 和构建来源证明。

下载校验值见 [SHA256SUMS](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.0-rc.1/SHA256SUMS)，版本、来源提交与签名状态见 [release.json](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.0-rc.1/release.json)。使用方法见 [README](https://github.com/YTwsy/Team-Cross/blob/v0.2.0-rc.1/README.md)。
