# Team Cross v0.4.1

本版以 `Meta` 上已整合的数字分身、成员动态和阅读体验为基础，重点改进持续协作与分身工作台。

- **重新设计数字分身界面。** 侧边栏沿用协作会话的列表样式，支持折叠与展开。聊天正文和输入框统一宽度，标题与输入区固定，仅消息列表滚动；切换分身保留草稿和阅读位置。宽屏右侧展示任务、记忆和运行状态，窄屏使用抽屉。
- **在空间中持续协作。** 创建运行在自己 Mac 上的 Codex 分身，全空间成员参与同一条共享聊天；连续输入保留作者、来源和回复关系，也可以通过显式 @ 自己将问题交给默认分身。
- **后台工作与聊天并行。** 较长工作在独立 Work 会话中执行，主会话继续接收消息；进度与结果可回到原聊天、讨论或已绑定的发起会话。面板展示会话、任务提问、结果和记忆，并区分原生接收、已回复与任务完成。
- **成员动态与多会话阅读。** 一个空间支持多个协作会话共同阅读，改进长会话导航、过程折叠和侧栏滚动。成员动态集中呈现 @、回复与关注更新，并区分人的已读与分身处理状态。
- **修复关注来源与升级恢复。** 普通关注更新使用 Core 签发的来源编号，修复来源引用校验失败导致处理停滞的问题；已有不明回执仍需核对，不自动重放。改进 Core 升级和插件连接恢复，刷新插件界面时保留未发送草稿。

## 安装与升级

支持 Apple Silicon、macOS 14 及以上。下载 [App DMG](https://github.com/YTwsy/Team-Cross/releases/download/v0.4.1/Team-Cross-0.4.1-arm64.dmg) 或 [CLI](https://github.com/YTwsy/Team-Cross/releases/download/v0.4.1/teamcross-0.4.1-darwin-arm64.tar.gz)。升级前退出 Team Cross，通过原安装渠道更新；协作数据和工作目录保留。旧 `schema:2` 材料仍保留在磁盘，本版不加载或迁移。

安装包使用 **ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证**。Homebrew 稳定通道在公开资产验证完成后更新；本页出现自动写入的 Homebrew 小节，才表示公共 tap 安装验证已经完成。

发布来源为 `codex/release-v0.4.1`。发布流程检查 Go test/vet/race、Web check/test/build、两套嵌入资源、App/DMG/CLI 安装与生命周期、隔离 Homebrew 安装、SHA-256 和构建来源证明。界面另有真实浏览器的中英文、深浅主题、宽窄布局及滚动交互复核。本版不新增两台 Mac、跨网络 Tailcat 或真实模型的验收结论；Claude TUI 与 Tailcat 仍属实验性。

可从 [SHA256SUMS](https://github.com/YTwsy/Team-Cross/releases/download/v0.4.1/SHA256SUMS) 和 [release.json](https://github.com/YTwsy/Team-Cross/releases/download/v0.4.1/release.json) 核对产物与来源。操作说明见[中文指南](https://github.com/YTwsy/Team-Cross/blob/v0.4.1/docs/user-guide.md)和 [English guide](https://github.com/YTwsy/Team-Cross/blob/v0.4.1/docs/user-guide.en.md)。

## English

Team Cross v0.4.1 brings the local shadow, member activity, and reading improvements from Meta into a stable release.

- A redesigned shadow workspace adds collapsible sidebar lists, aligned chat and composer widths, a single message scroller, and preserved drafts and reading positions. Tasks, memory, and runtime details appear alongside chat on wide screens and in a drawer on narrow screens.
- Space members can share a continuous conversation with a Codex shadow running on its owner's Mac. Inputs retain their authors, sources, and reply targets; explicit self-mentions delegate to the member's default shadow.
- Independent Work sessions handle longer tasks while the main conversation continues. Progress and results return to the original chat, discussion, or bound initiating conversation. Receipt, reply, and task completion remain separate states.
- Multiple collaboration sessions share one space, with improved long-conversation reading, process folding, and member activity for mentions, replies, and followed updates.
- Core-issued source IDs fix validation failures in ordinary followed updates. Unknown historical receipts still require reconciliation and are not replayed automatically. Core and plugin upgrades better preserve connections and unsent drafts.

For Apple Silicon Macs running macOS 14 or later. Download the [App](https://github.com/YTwsy/Team-Cross/releases/download/v0.4.1/Team-Cross-0.4.1-arm64.dmg) or [CLI](https://github.com/YTwsy/Team-Cross/releases/download/v0.4.1/teamcross-0.4.1-darwin-arm64.tar.gz), quit Team Cross, and update through the original installation channel. Data and working directories remain; old `schema:2` material is not loaded or migrated.

Packages use **ad-hoc signing without Developer ID signing or Apple notarization**. The pipeline verifies engineering gates, both embedded frontends, installation and lifecycle behavior, isolated Homebrew installs, checksums, and build provenance. This release adds no new two-Mac, cross-network Tailcat, or real-model acceptance claims. Claude TUI and Tailcat remain experimental.
