# Team Cross v0.2.6

`v0.2.6` 是面向 Apple Silicon、macOS 14 及以上的正式版本。相比 `v0.2.5`，本版改进 Agent 通过 MCP 读取会话与批注的方式：先读取问题、用户补充和最终答复，需要时再展开过程记录与工具输出，减少无关内容和重复长引用进入上下文。

## 主要变化

- 会话读取新增 `answers`、`conversation`、`outline` 和 `items` 视图。默认只返回最近轮次中的问题、用户补充与明确标记的最终答复，并保留轮次状态和来源；过程发言与工具输出可按需展开。
- 工具输出支持 `none`、`preview` 和 `full`。已知材料、轮次或记录 ID 时可以直接定位；轻量目录和轮内索引帮助 Agent 找到需要的内容，减少重复的状态与目录查询。
- 新导出材料保留来源阶段标记。缺少阶段标记的旧材料不会被猜测为最终答复；活跃历史仍先从 Provider 读取完整源页，再投影为所需视图。
- 个人辅助 MCP 与共享运行时都支持按 `annotationId` 精确读取批注；批注目录、状态查询和保存回复的回执使用精简字段，长讨论可以分页读取，避免反复携带引用全文。
- Agent 响应按包含 JSON 转义与封装开销的字节预算分页，并保留原文定位坐标。超限会返回明确错误，避免成功响应被外层静默截断。
- 补齐中英文 README、使用指南与英文产品示意图，并明确 GPLv3 许可证。

## 安装与升级

- **App**：下载 [Apple Silicon DMG](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.6/Team-Cross-0.2.6-arm64.dmg)，将 `Team Cross.app` 拖入“应用程序”并打开。
- **独立 CLI**：下载 [arm64 CLI](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.6/teamcross-0.2.6-darwin-arm64.tar.gz)，解压后将 `teamcross` 放入自己的 `PATH` 目录。

稳定 Homebrew Formula 与 Cask 会在公开 Release 资产完成复核后由后续发布阶段更新。Release 页面出现自动写入的 Homebrew 小节后，才表示对应稳定通道已完成公共 tap 安装验证。

升级前退出正在运行的 Team Cross，通过原安装渠道更新。协作数据与工作目录保留；旧 `schema:2` 材料仍保留在磁盘，但本版不加载或迁移它们。

安装包使用 **ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证**。首次打开若受到 macOS 提示，请先尝试打开 App，再到“系统设置 → 隐私与安全性”中确认。

## 验证与当前范围

上下文读取改进通过 Go test/vet、相关 race test、126 项 Web 测试和生产构建，并使用真实 Core HTTP/MCP 与 STDIO 工具枚举验证。固定回归场景覆盖最终答复筛选、轻量索引、精确批注、回复分页、UTF-16 定位及完整 MCP 响应预算；详细记录见 [Agent 上下文按需读取验证](https://github.com/YTwsy/Team-Cross/blob/v0.2.6/docs/agent-wiki/sources/validation/agent-context-reading-2026-09-27.md)。这些检查验证返回内容和载荷边界，不代表模型质量或 token 消耗的基准测试。

Tag 发布流水线会从本版提交重新运行工程门槛、arm64 CLI/App/DMG 构建、安装与生命周期、Homebrew 隔离安装、校验和与构建来源证明检查。本次没有新增真实模型、两台 Mac LAN、跨网络 Tailcat 或持续 DERP 验收；Claude Code 原生 TUI 与 Tailcat 继续保持实验性。
