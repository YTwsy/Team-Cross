# Team Cross v0.1.6-rc.3

`v0.1.6-rc.3` 是面向 Apple Silicon、macOS 14 及以上的预发布修订版。它沿用 `v0.1.6-rc.2` 的 Tailcat 跨网络协作、GitHub 来源证明和受保护 Homebrew RC 通道，集中修正 App 图标在 macOS 26 与 macOS 14 间可能出现的尺寸表现差异。

## 安装

- **App**：下载 [DMG](https://github.com/YTwsy/Team-Cross/releases/download/v0.1.6-rc.3/Team-Cross-0.1.6-rc.3-arm64.dmg)，将 `Team Cross.app` 拖入“应用程序”并打开。
- **独立 CLI**：下载 [arm64 CLI](https://github.com/YTwsy/Team-Cross/releases/download/v0.1.6-rc.3/teamcross-0.1.6-rc.3-darwin-arm64.tar.gz)，解压后将 `teamcross` 放入自己的 `PATH` 目录。

本预发布包使用 ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证。首次打开若受到 macOS 提示，请先尝试打开 App，再到“系统设置 → 隐私与安全性”中确认。

GitHub Release 创建后，同一 tag 的受保护 Homebrew 阶段会重新验证公开资产、构建来源和隔离安装，再通过独立 tap PR 发布 `teamcross-rc` 与 `team-cross@rc`。只有 Release 页面出现自动写入的 Homebrew 小节后，才表示公共 RC tap 已通过安装验证；在此之前请使用上述直接下载。

## 相对 v0.1.6-rc.2 的变化

- 保留现有 App 图标的 RGB、居中位置和非透明边界，只把白色底板的近不透明像素规范为完全不透明，并明确嵌入 sRGB 色彩描述，减少 macOS 26 对传统图标自动分层时的歧义。
- `Info.plist` 现在像已验证的 OpenSurge App 一样以无扩展名的资源基名声明 `CFBundleIconFile`；App 包内仍提供标准 `TeamCross.icns`。
- 构建时由同一源图生成全部 10 个 ICNS 尺寸表示，并在调用 `iconutil` 前移除临时图像继承的扩展属性，避免有效 iconset 被误判为 `Invalid Iconset`。
- 本次没有修改 WebGUI 图标或菜单栏状态图标。

## 当前范围

项目仍处于原型阶段，当前只提供 arm64 产物；Intel、自动更新和登录自启尚未提供。Tailcat 仍是实验性连接方式：本版本没有把既有同机隔离 Core 验收扩大成两台物理 Mac、不同 NAT、受限 UDP、持续 DERP 中继、睡眠或网络切换恢复的证明。

tag 发布流水线会在对应提交上重新执行 Go test/vet、相关 race test、Web check/test/build、嵌入资源一致性、arm64 构建、DMG/App/CLI 安装与生命周期、对应 Homebrew 渠道的隔离与公开安装，以及 CLI tar/DMG 的校验和和构建来源证明。它不运行真实模型、两台 Mac 网络或 Tailcat 公网 smoke；本机预检运行于 macOS 14，macOS 26 的最终显示仍需由对应系统上的实际安装确认。
