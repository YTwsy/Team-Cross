# Team Cross v0.3.0

`v0.3.0` 是面向 Apple Silicon、macOS 14 及以上的正式版本。本版以 `Meta` 分支的 `2acdab364bafbeaedf1078d09f19ef0beb2a4e5c` 为功能基础，加入 ChatGPT 本机插件、输入框资源引用、接收会话配对和空间工作台。原有材料、讨论与共同执行继续使用同一套本机 Core 和 WebGUI。

## 主要变化

- **在 ChatGPT 中使用现有 WebGUI。** 本机 Work/Codex 可以打开完整的 Team Cross 界面，浏览空间和资源库、读取材料、创建批注及保存回复。插件使用本机 stdio 与 Core，无需公网入站、Team Cross 云端后端或额外 Team Cross 账号；协作者仍通过 LAN 或实验性的 Tailcat 连接。
- **在输入框中引用材料与批注。** 输入 `@` 并进入 Team Cross，可以按空间名、材料标题、作者、版本或批注文字搜索。选中引用后，将具体材料版本或批注加入消息；用户发送消息时说明处理要求。检索与选择不会自动启动分析、回复或共同执行。
- **把选定内容带给当前个人 Agent。** 在资源库中选择材料版本或批注，生成固定读取入口，再通过“带回当前对话”向支持该能力的宿主发送读取提示。当前个人会话按明确引用读取内容；发送、已读取和已完成分别报告，结果不明时不自动重发。
- **接收会话配对。** 明确配对支持接收的原生 Codex 会话后，可以把选定引用和要求交给它，并查看提交、读取与完成回执。空间也可以创建独立的 Codex 接收会话；这一步不启用共同执行或 fork 来源。Claude Channel 继续保持实验性。
- **空间工作台。** 团队成员共用请求、简报和参与会话视图。可以把固定材料引用发给明确关联的接收目标，保存带版本检查的团队简报，并按需启用、暂停或更换一个专用会话角色。请求与结果按成员身份共享，断线或重启不自动重放输入。
- **插件安装与 App 同步。** 从 App 菜单“ChatGPT 插件…”或 WebGUI 设置页首次启用插件。后续 App 启动或重新打开时同步已启用插件，并连接当前 App 使用的 Core 数据目录。已有来源保留，旧目录不搬动、不复制、不合并；被移除或停用的插件不自动重装。安装成功与新版界面实际打开分别显示。

## 安装与升级

- **App**：下载 [Apple Silicon DMG](https://github.com/YTwsy/Team-Cross/releases/download/v0.3.0/Team-Cross-0.3.0-arm64.dmg)，将 `Team Cross.app` 拖入“应用程序”并打开。
- **独立 CLI**：下载 [arm64 CLI](https://github.com/YTwsy/Team-Cross/releases/download/v0.3.0/teamcross-0.3.0-darwin-arm64.tar.gz)，解压后将 `teamcross` 放入自己的 `PATH` 目录。
- **ChatGPT 插件**：安装 App 后，打开“ChatGPT 插件…”并点击“安装到 ChatGPT”。已有手动插件可选择“连接并启用自动同步”或“连接到当前数据”。复制 App 到 Applications 本身不会注册插件。若提示新版界面尚未加载，请在合适时机完全退出并重新打开 ChatGPT。

稳定 Homebrew Formula 与 Cask 会在公开 Release 资产完成复核后由后续发布阶段更新。Release 页面出现自动写入的 Homebrew 小节后，才表示对应稳定通道已完成公共 tap 安装验证。

升级前退出正在运行的 Team Cross，通过原安装渠道更新。协作数据与工作目录保留；旧 `schema:2` 材料仍保留在磁盘，本版不加载或迁移它们。

安装包使用 **ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证**。首次打开若受到 macOS 提示，请先尝试打开 App，再到“系统设置 → 隐私与安全性”中确认。

## 验证与当前范围

本版发布流程重新运行 Go test/vet、相关 race test、Web check/test/build、两套嵌入资源一致性、arm64 CLI/App/DMG 构建、DMG 安装与 Core/App 生命周期、隔离 Homebrew 安装、SHA-256 校验和构建来源证明。发布来源由 `codex/release-v0.3.0` 核对。

本机插件的使用范围为支持本机插件的 ChatGPT for Mac Work/Codex。普通 ChatGPT 网页、云端 Work 和手机端分别需要宿主支持与验收。本版不包含从 ChatGPT 原生消息选区直接采集片段、任意个人会话自动唤醒、云端 MCP Events 或永久监控。Claude 原生 TUI、Claude Channel 和 Tailcat 继续保持实验性；本次发布不新增两台 Mac LAN、跨网络 Tailcat 或持续 DERP 的验证结论。

可用 [SHA256SUMS](https://github.com/YTwsy/Team-Cross/releases/download/v0.3.0/SHA256SUMS) 校验资产，并从 [release.json](https://github.com/YTwsy/Team-Cross/releases/download/v0.3.0/release.json) 核对版本、来源提交、架构与签名状态。操作方法见[中文使用指南](https://github.com/YTwsy/Team-Cross/blob/v0.3.0/docs/user-guide.md)与 [English user guide](https://github.com/YTwsy/Team-Cross/blob/v0.3.0/docs/user-guide.en.md)。

## English

Team Cross v0.3.0 is a stable release for Apple Silicon Macs running macOS 14 or later. It is based on the Meta branch at `2acdab364bafbeaedf1078d09f19ef0beb2a4e5c`.

- Open the existing Team Cross WebGUI inside supported local ChatGPT for Mac Work/Codex sessions. Read material, add annotations, and save replies through the same local Core. No public inbound connection, Team Cross cloud backend, or extra Team Cross account is required.
- Use `@` in the composer to search Team Cross material versions and annotations. Add an exact reference to a message, then state the task before sending. Selecting a result does not start analysis or shared execution.
- Select material versions or annotations in the library, create a fixed reading entry, and use **Bring to current conversation** when the host supports it. Submission, reading, and completion have separate receipts.
- Pair a supported receiving Codex session or create a dedicated receiving session for a space. Send explicit requests with fixed references. The space workbench adds shared requests, a versioned brief, participating sessions, and an optional coordinator role.
- Enable the plugin once from **ChatGPT Plugin…** or the WebGUI settings. Later App launches synchronize the enabled plugin and bind it to that App's current Core. Existing source paths and data remain. Removed or disabled plugins are not reinstalled automatically.

Download the [App DMG](https://github.com/YTwsy/Team-Cross/releases/download/v0.3.0/Team-Cross-0.3.0-arm64.dmg) or [CLI archive](https://github.com/YTwsy/Team-Cross/releases/download/v0.3.0/teamcross-0.3.0-darwin-arm64.tar.gz). Quit Team Cross before upgrading through the original installation channel. Copying the App into Applications does not register the ChatGPT plugin; enable it from settings. Reopen ChatGPT when the connection page reports that the updated UI has not yet loaded.

Packages use **ad-hoc signing without Developer ID signing or Apple notarization**. The release pipeline checks engineering gates, both embedded frontends, installation and lifecycle behavior, isolated Homebrew installs, checksums, and artifact provenance. Old `schema:2` material stays on disk and is not loaded or migrated. Claude TUI, Claude Channel, and Tailcat remain experimental. This release does not add new two-Mac LAN, cross-network Tailcat, or sustained DERP acceptance claims.
