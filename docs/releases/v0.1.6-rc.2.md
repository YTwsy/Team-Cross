# Team Cross v0.1.6-rc.2

`v0.1.6-rc.2` 是面向 Apple Silicon、macOS 14 及以上的预发布修订版。它包含 `v0.1.6-rc.1` 的 Tailcat 跨网络协作与 GitHub 发布能力，并新增受保护的 Homebrew 稳定版/RC 双通道发布流程。本次修复 RC Formula 的稳定可执行文件路径，避免 Homebrew 升级后 Codex MCP 配置继续指向已经被移除的版本化 Cellar 目录。

## 安装

- **App**：下载 [DMG](https://github.com/YTwsy/Team-Cross/releases/download/v0.1.6-rc.2/Team-Cross-0.1.6-rc.2-arm64.dmg)，将 `Team Cross.app` 拖入“应用程序”并打开。
- **独立 CLI**：下载 [arm64 CLI](https://github.com/YTwsy/Team-Cross/releases/download/v0.1.6-rc.2/teamcross-0.1.6-rc.2-darwin-arm64.tar.gz)，解压后将 `teamcross` 放入自己的 `PATH` 目录。

本预发布包使用 ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证。首次打开若受到 macOS 提示，请先尝试打开 App，再到“系统设置 → 隐私与安全性”中确认。

GitHub Release 创建后，同一 tag 的受保护 Homebrew 阶段会重新验证公开资产、构建来源和隔离安装，再通过独立 tap PR 发布 `teamcross-rc` 与 `team-cross@rc`。只有 Release 页面出现自动写入的 Homebrew 小节后，才表示公共 RC tap 已通过安装验证；在此之前请使用上述直接下载。

## 相对 v0.1.6-rc.1 的变化

- 新增 RC 独立定义 `YTwsy/teamcross/teamcross-rc` 与 `YTwsy/teamcross/team-cross@rc`；稳定版无后缀定义不会因普通 `brew upgrade` 自动切换到 RC。
- Formula、Cask、稳定版和 RC 四种 Homebrew 安装都会提供同一个 App 或 `teamcross` 命令，配方通过成功安装收据执行双向互斥并保留协作数据。
- RC Formula 现在把版本化 `Cellar/teamcross-rc/...` 规范化为稳定的 `opt/teamcross-rc/bin/teamcross`，Core 升级复用与 Codex MCP 配置不会绑定旧 Cellar 版本。
- GitHub Release 成功后才启动 Homebrew 阶段：重新验证 annotated tag、`origin/main` 来源、SHA-256、release manifest、两份 artifact attestation 和公开资产安装。
- Homebrew 写入使用只安装到独立 tap 仓库的短期 GitHub App token，经受保护 PR、tap CI、自动合并与公共 `main` smoke 后，才把 PR、tap commit 和安装命令写回 Release。
- 自动化拒绝普通分支读取发布凭据、同渠道版本倒退、同版本元数据改写、无对应 PR 的既有远端分支和直接改写 tap `main`。

## 当前范围

项目仍处于原型阶段，当前只提供 arm64 产物；Intel、自动更新和登录自启尚未提供。Tailcat 仍是实验性连接方式：本版本没有把既有同机隔离 Core 验收扩大成两台物理 Mac、不同 NAT、受限 UDP、持续 DERP 中继、睡眠或网络切换恢复的证明。

tag 发布流水线会在对应提交上重新执行 Go test/vet、相关 race test、Web check/test/build、嵌入资源一致性、arm64 构建、DMG/App/CLI 安装与生命周期、对应 Homebrew 渠道的隔离与公开安装，以及 CLI tar/DMG 的校验和和构建来源证明。它不运行真实模型、两台 Mac 网络或 Tailcat 公网 smoke。

下载校验值见 [SHA256SUMS](https://github.com/YTwsy/Team-Cross/releases/download/v0.1.6-rc.2/SHA256SUMS)，版本、来源提交与签名状态见 [release.json](https://github.com/YTwsy/Team-Cross/releases/download/v0.1.6-rc.2/release.json)。使用方法见 [README](../../README.md)。
