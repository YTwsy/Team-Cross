# Team Cross v0.2.3

`v0.2.3` 是面向 Apple Silicon、macOS 14 及以上的正式稳定版本。相比 `v0.2.2`，本版集中改善多份材料、长对话和批注较多时的阅读与切换体验。

## 主要变化

- 协作详情改为整页滚动，材料与协作上下文共用吸顶工具栏。切换内容类型、进入或退出专注阅读时保留已读段落位置；目录与原文定位避让工具栏。
- 展开多份材料后，吸顶栏显示当前材料、固定版本与切换入口，向下阅读时也能切换材料或收起当前材料。已读版本恢复位置；材料卡外框不因展开而变色，作者的“发布新版本”和“撤回”靠右排列。
- 详情页收紧顶部与正文留白，批注的“加入选择 / 回复 / 复制提示”合并成对齐的操作行，回复与批注意见之间的间距更紧凑。参与成员在双栏长阅读时可平滑折叠，也可手动展开。
- 分享范围的摘要、阅读工具、导出说明和下一步按钮集中在吸顶区；导出说明仍可展开查看，目录跳转会避让实际工具栏高度。
- 资源库在阅读、勾选、收藏和后台同步时保持当前条目与分组顺序；手动刷新后再按最新使用记录排序。

## 安装与升级

- **App**：下载 [Apple Silicon DMG](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.3/Team-Cross-0.2.3-arm64.dmg)，将 `Team Cross.app` 拖入“应用程序”并打开。
- **独立 CLI**：下载 [arm64 CLI](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.3/teamcross-0.2.3-darwin-arm64.tar.gz)，解压后将 `teamcross` 放入自己的 `PATH` 目录。

稳定 Homebrew Formula 与 Cask 会在公开 Release 资产完成复核后由后续发布阶段更新。只有 Release 页面出现自动写入的 Homebrew 小节，才表示对应稳定通道已完成公共 tap 安装验证；在此之前可使用上面的直接下载。

安装包使用 **ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证**。首次打开若受到 macOS 提示，请先尝试打开 App，再到“系统设置 → 隐私与安全性”中确认。升级前退出正在运行的 Team Cross，通过原安装渠道更新；升级保留协作数据与工作目录。旧 `schema:2` 材料仍保留在磁盘，但本版不加载或迁移它们。

## 验证与当前范围

Tag 发布流水线会从本版提交重新运行 Go/Web 工程门槛、arm64 CLI/App/DMG 构建、App/CLI 生命周期和 Homebrew 隔离安装验证，并复核校验和与构建来源证明。功能验证记录见[资源库浏览顺序](../agent-wiki/sources/validation/library-browsing-2026-09-23.md)、[分享范围吸顶操作](../agent-wiki/sources/validation/publication-controls-2026-09-23.md)、[整页阅读](../agent-wiki/sources/validation/reading-scroll-2026-09-23.md)和[协作详情反馈](../agent-wiki/sources/validation/reading-layout-feedback-2026-09-23.md)；它们只对应各自注明的提交、设备和测试范围，本版构建仍以 tag 流水线为准。

本版仅提供 arm64 产物。Claude Code 原生 TUI 与 Tailcat 连接仍为实验性；这些工程、浏览器和本地安装验证不代表真实模型、两台 Mac LAN、跨网络 Tailcat 或持续 DERP 的新验收。

发布后可用 [SHA256SUMS](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.3/SHA256SUMS) 校验资产，从 [release.json](https://github.com/YTwsy/Team-Cross/releases/download/v0.2.3/release.json) 核对版本、来源提交、架构与签名状态。使用方法见[使用指南](../user-guide.md)。
