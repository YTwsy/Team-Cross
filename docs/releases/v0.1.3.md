# Team Cross v0.1.3

`v0.1.3` 是面向 Apple Silicon、macOS 14 及以上的预发布版本。会话、模型调用与代码执行仍保留在发起者的 Mac；参与者通过原生客户端或本地辅助工具共同查看、批注和继续同一个协作 fork。

## 安装

- **App**：下载 [DMG](https://github.com/YTwsy/Team-Cross/releases/download/v0.1.3/Team-Cross-0.1.3-arm64.dmg)，将 `Team Cross.app` 拖入“应用程序”并打开。
- **独立 CLI**：下载 [arm64 CLI](https://github.com/YTwsy/Team-Cross/releases/download/v0.1.3/teamcross-0.1.3-darwin-arm64.tar.gz)，解压后将 `teamcross` 放入自己的 `PATH` 目录。

本预发布包使用 ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证。首次打开若受到系统提示，请先尝试打开 App，再到“系统设置 → 隐私与安全性”中确认。

Homebrew tap 是 Release 之后的独立发布步骤，本次预发布不更新公共 Formula 或 Cask；`YTwsy/teamcross` 仍指向此前已发布的版本。

## 主要变化

- 加入实验性的 Claude Code 原生 TUI 协作路径，并让个人 Codex / Claude Code 可以通过本地工具辅助 Codex 或 Claude 协作。
- 发起者可从详情页把协作 fork 定位到个人 Codex Desktop；离线主机不再阻塞最近协作列表。
- 批注支持绑定对话文字或代码位置、保留独立草稿、单层回复，并可由共享原生运行时读取和回复。
- 重整协作详情的信息结构：共享状态并入执行信息卡，参与者与批注保持紧凑右栏，技术信息移入协作上下文标签。
- 简化批注编辑器和整体意见的视觉层级，并把说明文字放到“批注”标题右侧。
- 为 macOS App 使用新的应用图标；WebGUI 左上角与状态栏继续使用原有标识。

## 当前范围

项目仍处于原型阶段。当前只提供 arm64 产物；Intel、自动更新和登录自启尚未提供。Claude Code 接入仍为实验性，Codex Desktop 深链接只表示系统已接受打开请求，不代表完整窗口流程已在所有客户端版本验证。

本轮完成了 Go test/vet、相关 race test、Web 类型检查与 49 项交互测试、production Web 构建、真实浏览器布局复核，以及本地 DMG、CLI、App 生命周期和隔离 Homebrew 安装检查。两台 Mac 的真实 LAN、防火墙与睡眠恢复、完整原生窗口和首次系统批准流程没有重新验证，不能由同机测试替代。具体边界见 [批注与 WebGUI 验收](../agent-wiki/sources/validation/annotations-2026-09-13.md)、[个人 Codex Desktop 验收](../agent-wiki/sources/validation/personal-desktop-2026-09-13.md) 和 [Claude Code 原生 TUI 验收](../agent-wiki/sources/validation/claude-native-tui-2026-09-12.md)。
