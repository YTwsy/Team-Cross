# Team Cross v0.1.7-rc.1

`v0.1.7-rc.1` 是面向 Apple Silicon、macOS 14 及以上的预发布版本。本版为 Codex 和实验性的 Claude Code 增加创建时可选的信任模式，让可信同事在接管共享会话后使用邀请者已有的原生工具和权限。

## 相对 v0.1.6-rc.3 的变化

- 创建协作时可选择“受限模式”或“信任模式”。默认仍为受限模式；信任模式继承邀请者的个人 MCP、插件、hooks、网络和命令权限，以及原生已启用且可用的浏览器、电脑控制等能力。
- 模式在创建时确定，绑定预览、创建请求、持久化记录和邀请。详情与邀请确认页显示授权范围；首版不支持切换，恢复沿用同一模式与同一个 fork。
- Codex 信任模式保留原生权限配置和个人工具，原生 hook 确认正确写回邀请者端。修正远端 TUI 的 hooks/skills 发现，使客户端能够完成初始化。
- Claude 信任模式直接使用邀请者的原生配置目录创建新 fork。结束共享只停止本次 worker，保留个人 daemon 和其他会话；等待 worker 完全退出后再恢复，避免立即恢复产生另一会话。
- 保留共享批注工具、输入交接、写入去重及结束访问控制。两种 Provider 的默认受限行为均完成回归。

## 信任模式的含义

请仅对你信任的协作者选择信任模式。工具仍在邀请者的 Mac 上运行，可能访问工作目录以外的数据、调用外部服务，并使用邀请者已有的服务授权；加载工具和创建或恢复会话也可能执行原生 hooks。

信任模式遵循原生客户端、组织策略和 macOS 授权，不会自动启用未安装或未授权的能力，也不会强制跳过原生审批。继承范围是主机可解析的原生配置和可用环境，不是来源进程全部临时命令行参数、环境变量或 Desktop 私有服务的精确快照。结束共享会撤销后续入口访问，不会回滚已经执行的工具操作。

## 安装

- **App**：下载 [DMG](https://github.com/YTwsy/Team-Cross/releases/download/v0.1.7-rc.1/Team-Cross-0.1.7-rc.1-arm64.dmg)，将 `Team Cross.app` 拖入“应用程序”并打开。
- **独立 CLI**：下载 [arm64 CLI](https://github.com/YTwsy/Team-Cross/releases/download/v0.1.7-rc.1/teamcross-0.1.7-rc.1-darwin-arm64.tar.gz)，解压后将 `teamcross` 放入自己的 `PATH` 目录。

本预发布包使用 ad-hoc 签名，未使用 Developer ID 签名或 Apple 公证。首次打开若受到 macOS 提示，请先尝试打开 App，再到“系统设置 → 隐私与安全性”中确认。升级前请退出正在运行的 Team Cross，通过原安装渠道更新；升级保留协作数据和工作目录。

GitHub Release 创建后，同一 tag 的受保护 Homebrew 阶段会复核公开资产、构建来源与隔离安装，再通过独立 tap PR 发布 `teamcross-rc` 和 `team-cross@rc`。只有 Release 页面出现自动写入的 Homebrew 小节后，才表示公共 RC tap 已通过安装验证；在此之前可使用上述直接下载。RC 使用显式独立通道，不会把稳定安装者自动带到候选版。

## 验证与当前范围

信任模式已在 macOS 14.8.5 / arm64、Codex CLI `0.154.0-alpha.6.2`、Claude Code `2.1.270` 上完成真实 TUI 验收。Codex 与 Claude 分别测试受限和信任模式，共四轮；模型均限定为 `gpt-5.6-luna`。个人测试 MCP、hook、原生确认、批注读写及结束后同 session 恢复均有对应实测。工程检查包含 Go test/vet/race、Web check、53 项 Web 测试、生产构建和浏览器尺寸/主题矩阵。详细证据见 [信任模式验收](../agent-wiki/sources/validation/trusted-runtime-2026-09-16.md)。

tag 流水线会对发布提交重新执行工程门槛、arm64 CLI/App/DMG 构建、安装与生命周期检查、隔离及公共 Homebrew 安装、SHA-256 和 CLI/DMG 构建来源证明。发布流水线不运行真实模型。

本轮原生验收属于同一台 Mac 上的两个 Core，不代表两台 Mac LAN、Tailcat 跨网或持续 DERP 验收；专用 Desktop 窗口和实际浏览器/电脑控制工具尚未专项实测。Claude Code 接入仍为实验性，Claude Desktop 与 OAuth/Keychain 流程未验收；零输入 fork 的原生历史尚未落盘时，WebGUI 历史暂不可读，释放后也不保证可恢复。当前只提供 arm64 产物，尚无 Intel、自动更新或登录自启。
